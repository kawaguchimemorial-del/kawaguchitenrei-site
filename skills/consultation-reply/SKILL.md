# Skill: 事前相談・お問い合わせへの返信メール作成

作成日: 2026-09-16 / 松澤依頼。初回の実例（2026-09-14〜16 の事前相談3往復）から標準化した。

## 目的

サイト・広告LP・GBP から届いた事前相談・お見積り依頼に、松澤名義で返信するメール文案を作る。
説明の順番・言い回し・価格の出し方を固定し、毎回ゼロから考えなくてよくする。

**このスキルで作るのは「文案」まで。送信は松澤が Gmail から行う。**

---

## 0. 絶対に守ること

- **個人情報をリポジトリに書かない。** お客様名・電話・メール・病院名・故人名は、チャットの文案にだけ出す。
  `docs/` `skills/` `tmp/` に保存する記録は「事前相談・20名・無宗教・市民葬の質問」のような属性だけにする
- **価格は CLAUDE.md §9 と `lib/plans.ts` の正本だけ。** 見積書 PDF に書かれた数字は、その PDF を読んで転記する（推測しない）
- **§11 のトーン。** ご容態が思わしくない段階のご家族が相手。煽らない・断定しない・押し売りしない。
  「必ず」「絶対」「最安」「今すぐ」を使わない。「お祈り申し上げます」で結ぶが、ご存命の方に「お悔やみ」は書かない
- **署名は松澤名義**（有岡は使わない）。フォーマットは §6

## 2. 返信の型（3段階）

### 2-1. 初回返信（プラン一覧＋流れ＋ヒアリング）

順番は固定：
1. お礼と、ご家族の状況への一言（重く受け止めている／落ち着いて準備できるようお手伝いする）
2. **基本プラン6つ**（§9 の通常価格と会員価格を併記。会員価格の適用条件は §3）
3. 各プランに共通で含まれるもの（搬送20km・安置とドライアイス・棺・骨壺・白木位牌・祭壇基本設え・霊柩車・仏衣・役所手続き代行）
4. **別途必要になりうるもの**（火葬料・宗教者へのお礼・料理返礼品・安置延長・20km超搬送・他式場の使用料）
5. **お見積りのために伺う6項目**：①気になるプラン ②人数 ③宗教・宗派 ④入院先・所在地 ⑤安置場所の希望 ⑥火葬場の希望
6. **いざというときの流れ7ステップ**（電話→お迎え→安置→打合せ→役所手続き→式・火葬→葬儀後）
7. 「小さなことでも」の一言と署名

### 2-2. 2回目（回答を受けてプラン提案＋会員登録案内）

- 人数・宗教から候補を **2つ** に絞って提案（例：20名・無宗教 → 夕暮れ家族葬 か 家族葬）。1つに決めつけない
- 各候補の価格・日程の違いを3〜4行で
- 無宗教なら「宗教者へのお礼は不要。お花・音楽などご家族らしい形を一緒に考える」
- **会員登録の案内**：メール返信で登録できる。必要4項目＝①登録者名 ②郵便番号・住所 ③電話 ④対象者名。
  受領→登録→概算見積を作成→送付をもって登録完了
- お見積りの前提を明記（お迎え先・安置＝当社安置室・火葬場＝めぐりの森・候補プラン）

### 2-3. 3回目以降（見積送付・制度説明・比較）

- 冒頭で「登録完了・今後は会員価格」を伝える
- 質問された制度（市民葬など）は §4 の定型で説明
- 見積は **概算合計＋内訳の考え方**（プラン−割引＋追加分）を並べる。細かい単価は PDF に任せる
- **見積の読み方の注意** を必ず添える（§5）

## 3. 会員価格（事前相談会員価格）のルール

- **問い合わせが来ただけでは会員扱いにしない**（2026-09-14 松澤判断）。初回返信では「会員登録いただいた方に適用。登録方法もご案内できます」と書く
- 登録は §2-2 の4項目をメールで受ければよい。登録後の返信から会員価格でご案内
- 見積書上は「割引：事前相談会員登録 −100,000円」の行で表す（市民葬は割引対象外）

## 4. 川口市民葬の説明定型

出典は `lib/plans.ts` の `citizenFuneralInfo`。

- **制度**：川口市の葬祭事業。条件は「申請者または故人が川口市民」＋「めぐりの森で火葬」。当社は登録業者で申請を代行
- **費用**：仕様1（通夜・告別式）231,000円／仕様2（火葬のみ）143,000円。市の補助は市から業者へ支払われ、利用者に現金は出ない
- **含まれるもの**：祭壇（白木or生花）・供物・焼香用具・帳面類・後飾り・安置2日・棺・霊柩車（安置先→火葬場）・骨壺骨箱・仮位牌・枕飾り・線香ろうそく
- **別途**：式場使用料（川口メモリアルホールでも別途）・会場設備音響・病院からの搬送・遺影写真・火葬料・供花・料理返礼品・宗教者
- **正直な評価（2026-09-16 松澤）**：必要なものを足すと当社では **690,000円スタート**。20年前からの制度で「白木祭壇込み」など当時の組み方になるため、**少人数でゆっくり行う葬儀には不向き**。向くのは大人数で項目を細かく調整して抑えたい場合。今回のような20名前後ならセットプランの方がお得

セットプランと市民葬の差で強調する点：セットプランには **式場使用料無料・病院からの搬送・遺影写真・司会運営スタッフ** が含まれ、市民葬では別途。

## 5. 見積書を送るときの注意書き（毎回添える）

- **安置日数**：火葬場の予約が3日ほど待つ前提で安置・ドライアイスを追加している。早ければ安く、延びれば加算
- **火葬料**：めぐりの森の火葬料（例 30,000円・待合室含む）は実費でお見積りに含めていない
- **任意の加算**：湯灌・古式湯灌（ラストメイク）・棺の中のお花・祭壇グレードアップなどは希望時のみ。**必ず事前に説明してから進める**
- 「お見積りは何度でも作り直す」

## 5-1. 相談ごとの資料置き場（松澤運用・2026-09-16）

`F:\onedrive\OneDrive - 株式会社川口典礼\ホームページ事前相談\` に相談ごとのフォルダを作って溜める。
フォルダ名は `<YYYYMMDD>　<姓>　事前相談`。中に見積 PDF（プラン別）、先方メールの写し、送った文案などを置く。

- 返信文案を作る前に、該当フォルダの中身を Read で確認する（PDF は画像として読める）
- 概算合計と内訳はそこから転記する。フォルダに無い数字は書かない
- リポジトリ側にはフォルダの存在と属性だけを記録し、中身（個人情報）は写さない

## 6. 書式

- **スマホ前提**：1行 20 字前後で改行。表は使わない。プランは「▼ プラン名／通常価格／会員価格／説明」の縦積み。区切りは `━━━` 、見出しは `■`
- 全文をコードブロックで出す（ユーザーがそのままコピーする）
- 署名：
  ```
  ――――――――――――――――
  株式会社川口典礼　松澤
  〒333-0833
  埼玉県川口市西新井宿440-1
  TEL 0120-963-765
  （24時間365日）
  ――――――――――――――――
  ```
- 文案の後に「送信前に確認いただきたい点」を最大2つ。正本に無い数字を入れた場合は必ずここで断る
