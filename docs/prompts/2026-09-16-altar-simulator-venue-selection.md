# 祭壇シミュレーター（F:\kawaguchi-altar-simulator）へ渡すプロンプト

料金の出典は `skills/consultation-reply/crematorium-and-hall-fees.md`（公式ページ由来・確認日 2026-09-16）。

---

以下をそのまま貼り付ける。

```
祭壇シミュレーターに「火葬場・式場の選択」を追加してください。現在は「自社式場（川口メモリアルホール）＋川口市めぐりの森」が暗黙の前提ですが、それ以外の組み合わせでも概算が出るようにします。

## 追加する UI
プラン・ランク選択の後（オプションの前）に「式場・火葬場」の選択を1ブロック追加。
既定は「自社式場（川口メモリアルホール）＋川口市めぐりの森」で、これを選んでいる限り現在の計算と1円も変わらないこと。
「自社式場＋めぐりの森以外」を押すと、次の2つのセレクトが出る。

- 式場：川口メモリアルホール／戸田葬祭場（光の間・せせらぎの間・思食の間）／戸田サービス館／谷塚斎場（東館・すばる・西館・南館・星館）／町屋斎場（旅・雪）
- 火葬場：川口市めぐりの森／戸田葬祭場／谷塚斎場／町屋斎場／臨海斎場

火葬場ごとに火葬炉の等級（最上等・特別室・特別殯館など）も選べるようにする（既定は最上等／普通炉）。

## 計算ルール（data/simulatorData.ts にデータとして持つ。ロジックにベタ書きしない）

### 火葬料
すべて「実費」。見積の合計には入れず、別枠「実費項目」として見積書の右側の枠と別紙に表示する（現在の「実費項目 ＿＿＿円」の欄を使う）。参考額として下記を表示する。
- めぐりの森：大人 市内 30,000円／市外 100,000円（待合室含む）※非課税
- 戸田葬祭場：特別殯館 177,000／特別室 107,500／最上等 80,000 ※非課税
- 谷塚斎場：特別殯館 177,000／特別室 107,000／最上等 74,000 ※非課税
- 町屋斎場：特別殯館 160,000／特別室 123,000／普通炉 87,000 ※非課税
- 臨海斎場：組織区外 88,000 ※非課税（川口市民は組織区外）

### 待合室
- めぐりの森：火葬料に含む（加算なし）
- 戸田葬祭場：1席 990円（税込）× 来場者数。参列人数の入力値から自動計算して**見積に計上**
- 谷塚斎場：実費（参考：蓮の間 40,700／鶴の間 26,400／楓の間 24,200／藤の間 22,000／イス席 990円/席）。実費枠に表示
- 町屋斎場：実費（参考：鶴の間 74,800／星の間 40,700／月の間 34,100／梅の間 19,800）。実費枠に表示
- 臨海斎場：実費（参考：組織区外 60,000）。実費枠に表示

### 収骨容器（骨壺）
- めぐりの森・谷塚斎場：現在どおり骨壺オプション（白瀬戸 14,300円〜）を**見積に計上**
- 戸田葬祭場・臨海斎場：火葬料に無料容器が含まれるため、骨壺オプションを既定「火葬場の無料容器（0円）」にし、有料の骨壺を選んだ場合だけ加算
- 町屋斎場：骨壺は実費（斎場で購入）。骨壺オプションは非表示にし、実費枠に「収骨容器（実費）」と表示

### 式場使用料
- 川口メモリアルホール：0円（現在どおり）
- それ以外：実費。参考額を実費枠に表示
  - 戸田葬祭場：光の間 297,000／せせらぎの間 198,000／思食の間 253,000（税込）
  - 戸田サービス館：公式非公開。金額は data に空欄で持ち「要確認」と表示（松澤が後で入れる）
  - 谷塚斎場：東館 363,000／すばる 286,000／西館 286,000／南館 275,000／星館 220,000（税込）
  - 町屋斎場：旅 242,000／雪 275,000（税込）

### 外部設営費
川口メモリアルホール以外の式場を選んだら、**「外部設営費一式 100,000円（税抜）」を見積に自動計上**する（税込表示なら 110,000円）。数量1・削除不可。

## 見積書（ProposalDocument）への反映
- 実費項目の欄に、火葬料・待合室・式場使用料・収骨容器の各参考額と合計を「実費（概算・非課税含む）」として表示
- 概算合計金額とは別に「実費を含めた総額の目安」を1行追加
- 別紙「必要に応じてかかる物」の 1）火葬・斎場関連 の例示を、選んだ火葬場の実額に差し替える

## 守ること
- 既定（自社式場＋めぐりの森）の計算結果・表示を変えない。既存のテストがあれば通す
- 料金はすべて data に「出典URL・確認日 2026-09-16」のコメント付きで持つ
- 税区分（非課税／税込／税抜）を項目ごとに持ち、表示に混ぜない
- 変更後、プラン×式場×火葬場の代表3通り（自社＋めぐりの森／戸田＋戸田／谷塚＋谷塚）の PDF を出力して確認する

- 臨海斎場 https://www.rinkaisaijo.or.jp/guide/price/
```
