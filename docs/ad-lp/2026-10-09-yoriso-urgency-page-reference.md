## 0. 結論

- **参考になるのは「見た目」ではなく、最初に置く言葉の順番。** よりそうは「会社名」ではなく「あなたの状況」から始め、「葬儀を決める前に、搬送だけ先に頼める」と伝えてから電話番号を出している
- 当社LPは同じ内容（「すぐに移動を」と言われた／何も決まっていなくて大丈夫）をすでに持っているが、**最初の画面の下にあり、届くのは入口の約1割**（10/6：最初の画面95人 → 急ぎの案内7人）
- **ただし今は変えない。** 10/21 の旧LPとの本比較の前に画面を変えると比較が成り立たない。10/5 の会議でも「LPの見た目をタップ率の低下を理由に変えない」と決めている
- **今やるのは、事実の確認だけ（下記5項目、松澤の回答待ち）。** 回答が揃えば、10/21 以降の改修案の材料になる
- 割引・返金保証・「今すぐ」・警告アイコン・時間の約束は取り入れない

## 2. よりそうのページ構成（上から）

1. 見出し「お亡くなり・ご危篤の場合」— **会社名ではなく状況名**
2. 「このような状況の方へ」— ご臨終・ご危篤を宣告された／**病院から搬送を急がされている**／急な事でどうすべきか分からない
3. **「ご依頼を検討中でも、先に搬送のみ承ります」**「お葬式を依頼するかどうかは、ご搬送後にお打合せをした後で決められます」（搬送のみは別途費用と注記）＋カード決済のロゴ
4. 「全国対応」「病院まで1時間程度でお迎えにあがります」＋オペレーター写真
5. 大きな電話ボタン「ここをタッチして今すぐ電話をかける」
6. よくある質問8問（**料金より前**）— 連絡のタイミング／何をすべきか／**病院紹介の葬儀社が高額だった（安置済みでも対応）**／長距離搬送の費用／自宅で安置できない／返金保証／運営会社／菩提寺がない
7. 状況の一覧をもう一度 → プラン・料金（通常価格と「資料請求等で3万円引」を併記）
8. 火葬料の地域別目安（川口市30,000円の記載あり）、**プランに含まれる安置日数と超過1日33,000円、月別の平均超過日数**
9. 返金保証、安置方法（自宅／預かり）、会員割引（最大12万円引）

見た目：白地に赤・黄の強調、感嘆符の警告アイコン、イラスト多用。最初の画面に料金はない。

## 4. 2周目：データとルールで絞る

### データで見ると

- **最初の画面から下へ進むのは約1割**（10/5：89→14人、10/6：95→10人、10/7速報：90→17人）。下にある良い言葉は、ほとんど読まれていない。→ A・D を上へ寄せる考え方自体は数字と合う（計測）
- **電話タップの大半は下の固定バーから**（10/4：7人中6人、10/6：5人中4人）。読まずに押す人が多く、文章の位置を変えてもタップ数が動く保証はない（計測）
- **1日のタップは3〜8人。** この規模では1〜2週間で改修の良し悪しは判定できない（計測）
- 入口の多くが Cross-network（ディスプレイ等）の日がある。よりそうの「状況から入る」型は検索で急いでいる人向けで、**ディスプレイから来た事前検討の人には合わない**。当社LPは1ページで急ぎ・事前・会葬の3者を受けている点がよりそうと違う（広告運用）
- 旧LPとの本比較は **10/21（9/26以降の期間）**。それまでに画面を変えると比較できなくなる（計測・広告運用が一致）

### 社内ルールで見ると

| 要素 | 判定 | 理由 |
|---|---|---|
| A 状況から始める | **10/21以降に検討** | 本比較を崩さないため。会社名・自社式場の見出しは地域ブランドとして残す（地域ブランド） |
| B 搬送のみ | **事実確認が先** | 当社が受けているか、費用をどう説明するか不明。正本にない金額は書かない（§9・§14） |
| C お迎えの時間 | **使わない** | 10/5 決定「すぐ伺います（時間の約束）」は使わない。道路・時間帯で守れない約束になる（§11） |
| D 病院紹介を断ってよい | **採用候補（低リスク）** | 本サイトのコラムに既にある事実。煽りではなく安心材料。「安置済みでも依頼できる」は事実確認が先 |
| E カード決済 | **事実確認が先** | 対応ブランドを推測で載せない |
| F 安置日数・超過料金 | **事実確認が先** | 正本にない数字。火葬料（めぐりの森・川口市民30,000円）は本サイトで既出（`lib/area-local-guide.ts`）なので、注記に足すのは低リスク |
| G FAQを前へ | **D と合わせて急ぎの案内の中に1問だけ** | FAQ全体を上げると最初の画面が長くなり、電話が遠のく（モバイルUX） |
| H 「今すぐ電話」 | **使わない** | 「今すぐ」は急かす表現（§11）。「タップで発信できます」は既にある |
| 割引（3万円・12万円引）・返金保証 | **取り入れない** | 緊急層に会員割引を主訴求しない方針。返金保証は当社に制度がない |
| 警告アイコン・赤黄の強調 | **取り入れない** | ご逝去直後の方に警告の記号は強すぎる（ご遺族心理）。§21 で見た目は自由だが、言葉と配慮の規律は同じ |
| 全国型の数字（年間77,000件等） | **対象外** | 当社は「創業20年・年間約260件」を既に表示。規模で張り合わない（地域ブランド） |

## 6. 10/21 以降の改修案（回答と本比較の結果しだい・未合意）
