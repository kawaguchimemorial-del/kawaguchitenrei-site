# NEXT UP の GTM 設定レビューと DG バナー別レポートの分析（2026-09-17）

作成日: 2026-09-17 / 担当: Claude Code（松澤依頼）/ GTM は API 読み取りのみ・変更なし

## 1. GTM（GTM-TJWKD4WB）に先方が追加したもの

9/16 に先方が Default Workspace へ追加（未公開）。ライブは v8。

| 追加 | 種類 | トリガー | 判定 |
|---|---|---|---|
| コンバージョン リンカー | gclidw | All Pages | OK（サイト全体で問題ない） |
| 電話タップCV | Google Ads CV（18085441345 / l2enCMCw-KQcEMHe569D） | **既存の「Clik-電話リンク」（Click URL contains `tel:`）** | **NG：サイト全体の電話タップが広告CVになる。`/lp/` 限定になっていない** |
| フォーム入力完了 | Google Ads CV（18085441345 / FqksCK_766QcEMHe569D） | **新規「LPフォーム入力完了」＝ ページビュー・Page URL contains `#lp-contact-complete`** | **NG：`#lp-contact-complete` は完了画面の要素IDで、URLには付かない。このトリガーは一度も発火しない** |

さらに、ワークスペースに **「GA4 - lp_* (広告LP)」タグ（9/12作成・停止なし）** が残っている。ライブ v8 では撤去済み（撤去理由：転送タグを足すと全イベントが2件ずつ記録される）。**このままワークスペースを公開すると、撤去したタグが復活し二重計上が再発する可能性がある。**

### 直し方

1. 電話タップCV：トリガーを新規「LP 電話タップ」＝ リンククリック・Click URL contains `tel:` **かつ Page Path starts with `/lp/`** に付け替える
2. フォーム入力完了：トリガーを新規「LP フォーム完了（要素表示）」＝ **要素の表示**・選択方法 ID・要素ID `lp-contact-complete`・「1ページにつき1回」・Page Path starts with `/lp/` に付け替える。ページビュー型の「LPフォーム入力完了」は削除
3. 「GA4 - lp_* (広告LP)」タグと「Custom Event - lp_* (広告LP)」トリガーがワークスペースに残っていれば **削除**（`lp_*` は gtag 直送で届いている）
4. プレビューで `/lp/` の電話タップ・フォーム送信テスト（`?analytics=on` は使わず、プレビューの Tag Assistant だけで確認）
5. 公開。バージョン名「LP 広告CV（電話・フォーム）追加、/lp/ 限定」

当社に編集権限があるので当社で直せる。先方に直させると往復が増えるため、**当社で修正→先方に「こう直した」と報告**が早い（松澤判断待ち）。

### 読み取り

1. **縦向き画像はほぼ配信されていない**（表示 25〜42 回）。枠が無いので、新規でも縦は作らなくてよい
2. **正方形は CTR が高く（3〜4%）横は低い（0.5〜0.8%）が、表示は横が圧倒的に多い。** 横は「面が取れる」形、正方形は「押される」形。両方必要
3. **価格訴求（88,000円・8.8万見出し）が CV の上位にいる。** ただし 2026-08-03 の松澤判断（価格で選ぶ層は広告で追わない・DG の 8.8万アセットは停止）と矛盾したまま 9/10 まで配信されている。見出し「直葬8.8万～」も両KPで稼働中。**バナー差し替えのときに、価格訴求の画像・見出しをすべて外す**（9/12 メール②で「成績がよくても費用の安さを訴求しているものは外す」と伝達済み）
4. 価格以外で効いている軸は **「めぐりの森 車で5分」「自社ホール・駐車場70台」「川口市の葬儀なら川口典礼へ」**。9/12 に送った14点はこの軸で作っているので方向は合っている
5. 「川口市内で家族葬・市民葬をお探しの方へ」は正方形で CTR 3〜4%・CV 2 と堅い。文言は残す価値がある

## 4. 実施記録（2026-09-17・当社で API 修正、未公開）

松澤判断「当社で直す」により、Default Workspace を Tag Manager API で修正した。**公開はしていない。**

| 操作 | 内容 |
|---|---|
| 作成 | トリガー「LP 電話タップ」：リンククリック・Click URL starts with `tel:` かつ Page Path starts with `/lp/`（既存「Clik-電話リンク」と同じ waitForTags=false / checkValidation=false） |
| 作成 | トリガー「LP フォーム完了（要素表示）」：要素の表示・ID `lp-contact-complete`・1ページ1回・DOM変更を監視（送信後に描画されるため必須）・Page Path starts with `/lp/` |
| 更新 | タグ「電話タップCV」→ LP 電話タップ、「フォーム入力完了」→ LP フォーム完了（要素表示） |
| 削除 | トリガー「LPフォーム入力完了」（発火しないページビュー型） |
| 削除 | タグ「GA4 - lp_* (広告LP)」・トリガー「Custom Event - lp_* (広告LP)」（v8 で撤去済みの転送タグの残骸） |

ワークスペースの変更一覧：追加4（リンカー・電話タップCV・フォーム入力完了・LP 電話タップ・LP フォーム完了）／削除2（lp_* タグ・トリガー）。既存の GA4 タグ5本は無変更。

1. GTM → ワークスペース「Default Workspace」→ 右上「プレビュー」→ URL に `https://kawaguchitenrei.com/lp/` を入れて接続
2. LP の電話ボタンを押す（実際に発信しない）→ Tag Assistant で **「電話タップCV」が Fired**、**「GA4-clik_tel」も Fired**（既存どおり）
3. `https://kawaguchitenrei.com/` の電話ボタンを押す → **「電話タップCV」は Not Fired**（`/lp/` 限定の確認）
4. `/lp/contact/` でフォームを送信（氏名「テスト」・本文に「テスト送信」と書く。GAS に届くので送信後にシートで削除）→ 完了画面が出た瞬間に **「フォーム入力完了」が Fired**
