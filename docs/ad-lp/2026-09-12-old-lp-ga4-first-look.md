## 2. ⭐ ここから分かること

### (1) 8月のフォーム送信は、GA4上で **0件**

広告のレポートでは **8月のコンバージョンは57件**だった。
一方、旧LPのGA4では

- フォームに入力を**始めた**人：**6人**
- フォームを**送信した**人：**0人**

**57件のうち、フォーム送信は1件も含まれていない。**

直近90日まで広げても `form_submit` は **4件**しかない。

| 期間 | form_start | form_submit |
|---|---|---|
| 2026-08 | 6 | **0** |
| 直近90日 | 21 | **4** |

→ **8月のCV57件は、ほぼ全量が電話タップである**ことが、広告側とは独立した計測で裏づけられた。

これは松澤が9/12に述べた「なぜか電話タップが無駄に上がっている」、
および P-MAX の13件が電話タップの積み上がりだったという先方の説明と**完全に一致する**。

> **AdSiP を導入して「実際に鳴った数」を押さえる方針は、これで根拠が固まった。**
> いま広告が最適化の目標にしている57件は、実体の分からない数字である。

### (2) 登録されているキーイベントが、1件も発火していない

旧LPのGA4に登録されているキーイベント：

```
close_convert_lead, qualify_lead, purchase, 電話CV, 電話Cv
```

**このうち8月に発生したものは1つもない。**
（8月のイベントは page_view / session_start / first_visit / user_engagement / scroll / click / form_start の7種のみ）

- `close_convert_lead` `qualify_lead` `purchase` は **GA4の初期値**で、当社と関係がない
- **`電話CV` と `電話Cv` は、大文字小文字違いの重複**。GA4のイベント名は大文字小文字を区別するため、
  これは**設定ミスが残ったまま**になっている
- いずれにせよ**どちらも0件**なので、**このプロパティのキーイベントは機能していない**

→ **旧LPのGA4は、設置されているだけで、コンバージョンを1件も測っていない。**

### (3) ページがほとんど読まれていない

| | 数値 | セッション比 |

**10人に9人は、ページの下まで到達していない。** 平均54秒で離脱している。

96.4%がスマートフォンであることを踏まえると、**上部で判断が終わっている**と考えられる。
新LPのファーストビュー（「まだ何も決まっていなくて、大丈夫です。」
「24時間365日、いまお電話がつながります。」）が効くかどうかは、
**この最初の数十秒で決まる。**

### (4) LPから本サイトへ、月24人が移動している

`click`（外部リンク）31件の内訳：

| 遷移先 | 件数 |

## 6. 当社側の宿題：GMO時代の計測一式（2026-09-12 追記）

**先方（NEXT UP）に投げる話ではない。当社アカウント内の整理である**（2026-09-12 松澤判断）。
前の代理店（GMO）が作った一式が、当社アカウントに残ったままになっている。

### 中身（`GTM-KLK8ZP2J` 公開中 v6）

| タグ | 種別 | 設定値 |
|---|---|---|
| Google タグ | `googtag` | `tagId = G-31H7JEBFPS` |
| GMO修正)Google広告_問合せ完了 | `awct` | `conversionId = 17177618705` / `conversionLabel = WHTiCIPQkdgaEJHS9v4_` |
| GMOgoogle広告電話タップ | `awct` | `conversionId = 17177618705` / `conversionLabel = xZJeCNbMkdgaEJHS9v4_` |
| コンバージョンリンカー | `gclidw` | — |
| GMOリマーケティング | `sp` | `conversionId = 17177618705` |

### 分かったこと

**`G-31H7JEBFPS`（「Google 広告アカウント」配下・データなし）は、このコンテナが使っていたGA4だった。**
コンテナがどこにも設置されていないため、プロパティにもデータが入っていない。
**2つは別々の謎ではなく、GMO時代の一式である。**

`conversionId = 17177618705` は Google 広告側のコンバージョンIDで、
**問合せ完了と電話タップの2つのラベル**を持つ。現在 NEXT UP 様が使っている
`GTM-N2J5GBXL` も構成は同じ（`__awct` ×2・`__sp`・`__gclidw`）なので、
**同じコンバージョンアクションを引き継いで使っている可能性がある。**

### 確認の順序

1. **いま確認する必要はない。** コンテナはどこにも設置されておらず、1件も発火していない
2. Google 広告アカウントの閲覧権限を得たとき（または月次報告の場）に、
   **`17177618705` のコンバージョンアクションが現在も有効か**を確認する
3. 現在のコンバージョンと重複していないことが確認できたら、
   `GTM-KLK8ZP2J` と `G-31H7JEBFPS` を削除してよい

**削除を急がない。** タグ名（「GMOgoogle広告電話タップ」）は、
**GMO時代から電話タップをコンバージョンにしていた**という記録であり、
「タップをCVにし続けてよいか」を議論する際の材料になる。

> コンテナは「【未使用】GMO時代（サイト未設置）」へ改名済み。次に見た人が迷わないようにしてある。
