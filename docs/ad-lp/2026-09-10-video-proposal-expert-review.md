# 動画（YouTube面）配信提案の検証 — 8人の専門家による討議

- 作成：2026-09-10
- 対象：2026年8月ご報告資料 8頁「9月以降は、動画クリエイティブの配信を検討していきたい。（Youtube面の配信）」および 14頁③④
- 経緯：初稿で「賛成。ただし順番はURL①整理が先」と書いたところ、松澤より **「本当に賛成でよいのか。大手の模倣で取れるのか。リスティング効果自体を疑っている。動画制作費は相手の売り込みではないか」** との指摘。全面的に再検討した。

## 結論

**反対。今期は実施しない。** 条件付き賛成でもない。

初稿の「賛成」は撤回する。理由は3つ。

1. **当社の方針（緊急の刈り取り → 事前相談）と、動画の役割（需要創出・認知）が一致しない。** これは 2026-08-26 に社内で既に結論が出ていた（`README.md` §2-3 / [[project-ad-lp-separate-from-main-site]]）。初稿はこの既決事項を踏まえずに書いた。
2. **予算が2桁足りない。** 13頁から逆算したYouTube面のCPMは¥1,028。川口市の成人約50万人に3回届けるには約¥154万＝**月予算¥959,754の1.6か月分**。1回でも¥51万（月予算の54%）。認知形成の最低ラインに届かない金額で始めても、効果が出ないのか金額が足りないのかが永久に分からない。
3. **同じ判断材料が、すでにDGの中にある。** URL①（非顕在ターゲティング）はCPA約¥48,800、KW①（検索行動ベース＝顕在層寄り）は約¥6,100。**当社の商圏では「非顕在に当てても取れない」という実験結果が、8月の自社の配信実績として出ている。** 動画は非顕在側の施策であり、URL①と同じ結果になる蓋然性が高い。

## 討議

### 1. ダイレクトレスポンス設計の視点 — 反対

葬儀は**発生型の需要**である。買う時期を顧客が選べない。認知広告が効くのは「買う時期を顧客が選べる商材」で、必要になった瞬間に選択肢として思い出してもらう必要があるもの（保険、車、住宅）。葬儀は違う。必要になった瞬間に、その場で検索するか、病院・役所で渡された案内から選ぶ。

**当社の実際の導線は既に把握できている**（[[project-brand-search-is-mostly-attendees]]）：役所や病院で葬祭事業の案内を入手 → 社名を検索 → 内容を見て問い合わせ。この経路のどこにも動画は入らない。

### 2. 葬儀業界の購買行動の視点 — 反対

川口市の年間死亡者数は概算5,000〜6,000人規模（人口約60万人からの当社概算）。月あたり約458件。当社は年間約260件＝シェア約4.7%。

**動画で川口市の成人50万人に届けたとして、その月に葬儀が必要になるのは0.09%。** 残り99.9%は「今は不要」で、必要になるまでに平均で何年もかかる。その間、月1回程度の露出で当社を覚え続けてもらう必要があるが、それは上記の予算では不可能。

### 3. 大手の模倣は成立するか — 反対（松澤の指摘は正しい）

小さなお葬式・よりそうが動画をやる理由は、当社と条件がまったく違うため。

| | 大手ポータル | 川口典礼 |
|---|---|---|
| 商圏 | 全国 | 川口市 |
| 到達単価の回収 | 全国のCPMで薄く広く回収 | 1市のみ。到達単価が割高になる |
| 売るもの | 「葬儀社を紹介する仕組み」＝地域の葬儀社を知らない人が対象 | 「この式場・このスタッフ」＝地域で既に接点がある人が対象 |
| 動画で伝わるもの | ブランドの安心感（全国どこでも同じ） | 立地・駐車場70台・めぐりの森まで車5分という**実利**。これは動画より地図と検索結果で伝わる |

**当社の強みは情緒ではなく地理と設備。** 動画はそれを伝えるのに最も向かない媒体である。

### 4. 計測・アトリビューションの視点 — 反対

動画の効果は「見た人が後日、社名や地域名で検索して問い合わせる」形で現れるため、動画面のCVでは測れない。ではSearch Consoleの指名検索表示回数で測れるかというと、**当社の指名検索は月40〜50回規模**（[[project-search-campaign-non-search-traffic]]）。この母数では、動画による増加分と月次のゆらぎを区別できない。

**測れない施策に、測れないまま金額を積むことになる。** 初稿で提案した「指名検索表示回数と着信で比較」は、母数を確認していなかった点で甘い。撤回する。

### 5. 動画マーケティングの視点 — 条件付きで反対（賛成側の最強の論拠と、その限界）

賛成側の最も強い論拠は「**事前相談（余命案件）層には効く可能性がある**」というもの。ご家族の余命告知を受けた方は、数週間〜数か月の検討期間があり、その間に情報を集める。この層は認知施策が届きうる唯一の層である。

しかし成立しない理由が2つ。

- **ターゲティングできない。** 「家族に余命告知を受けた人」を広告の配信対象として指定する手段がない。年齢・地域で絞っても大半は無関係な人に当たる（＝URL①と同じ構造）。
- **この層は既に検索している。** 「事前相談」「余命 葬儀 準備」「家族葬 費用」等で能動的に調べる。**検索で取れる層に、認知で当てにいく必要がない。**

したがって「事前相談層のために動画」も成立しない。事前相談層への投資先は、検索とサイトの受け皿の側。

### 6. ローカルSEO / MEO の視点 — 反対（同じ金額の使い道として、より確実な先がある）

当社が花ぜんセレモニーに競り負けている要因は、サイト品質ではなく**立地とローカルパック（地図枠）**（[[project-hanazen-competitive-position]]）。次の投資先はサイトでも動画でもなくGBP、というのが既に出ている結論。

葬儀を探す方が最初に見るのは地図であり、YouTubeではない。GBPの整備（写真・投稿・口コミ返信・属性）は**費用ゼロ**で、8月〜9月に実際に進めている。ここが終わる前に動画に金額を移す理由がない。

### 7. ユニットエコノミクスと発注ガバナンスの視点 — 反対

- 動画制作費は**代理店の収益源**であり、提案の動機に利益相反が含まれうる。それ自体は悪ではないが、**費用対効果の立証責任は提案側にある。**
- いまの広告費の中に、より確実な回収先がある。**URL① 約¥97,700／月（CV1〜2件）＋ 指名の説明のつかない ¥190,546／月 ＝ 月約28万円・年約346万円。** ここを整理すれば、新しい施策の原資は現予算の中から出る。
- **順序として、支出の説明がついていない月28万円を放置したまま、新しい支出を承認しない。** これは代理店への不信ではなく、発注側の当然の順序。

### 8. ご遺族心理・コンプライアンスの視点 — 反対（制作可能な素材の制約）

- 遺影・名札・会葬礼状・ご参列者・ご遺族が写るものは撮影・掲載できない。故人・喪主の情報も出せない。
- 結果として撮れるのは「式場の内観・外観・スタッフの説明」に限られる。**それは静止画とサイトで既に伝えている内容**であり、動画にする追加価値が小さい。
- また、葬儀の動画広告は**まだ必要でない方の画面に流れる**。ご家族の状況によっては不快に受け取られうる。当社のトーン（不安を煽らない・押し売りしない）と相性が悪い。

## 両論併記（取り下げられていない少数意見）

- **「認知ゼロでよいのか」** — 当社の認知形成が必要ないとは言っていない。ただしその手段は、動画広告ではなく**病院・役所・地域の実務接点とGBP**である。これは広告費ではなく営業と運用の領域。
- **「YouTube面のCPC¥19は本当に無価値か」** — P-MAX内の副次的な配信としてなら、少額が回る分には害はない。**問題は「動画クリエイティブを制作する」という支出**であって、既存アセットが自動でYouTube面に出ること自体を止める必要はない。
- **「大手が続けているのは効いているからでは」** — 全国モデルでは成立する。商圏が1市の当社では成立しない、というのが上記3の主張であり、大手が間違っていると言っているのではない。

## 松澤の「リスティング効果自体を疑っている」への回答

**この疑問は正当で、8月データはむしろそれを裏づける。**

| | 8月 |
|---|---|
| 媒体が計上したCV | 57件 |
| 当社の年間施行 260件からの月平均 | 約21.7件 |
| サイト上の電話ボタンのタップ | 33件 |

媒体CV57件と、実際の相談・受注の間に大きな開きがある可能性が高い。しかも57件のうち31件（DG18＋P-MAX13）はディスプレイ・動画面由来。

**したがって、次に必要なのは新しい施策ではなく「57件が何だったのか」の突き合わせ。** 9月から開始した電話着信記録と、フォーム受信の実数を、媒体CVと突き合わせる。これが出るまで、広告の新規投資は行わない。

なお、AIO（AI検索）や自然検索からの問い合わせが実際に発生している点も重要で、**広告以外の経路が機能している**ことを示す。広告予算の増額よりも、その経路（サイト・GBP・AIOでの引用）を厚くするほうが、当社の規模には合う。

## 会議での言い方（§3-5 に反映）

否定から入らない。「動画は当社には合わないと考えています」と結論を先に言い、理由は**予算規模の話**に置く（相手の提案の否定ではなく、当社の条件の話にする）。そのうえで「**同じ金額なら、URL①の整理と、いまの57件の中身の確認を先にしたい**」と、次の行動につなげる。

代替として先方に求めるもの：
1. URL①のターゲティング設定と、KW①への予算振り替え
2. 指名キャンペーンの配信面の内訳
3. P-MAX 13件の内訳
4. 動画は、上記3点が済み、かつ媒体CVと実件数の突き合わせができた時点で再提案していただく
