トップの見出しが決定的に違う。

> **「まだ何も決まっていなくて、大丈夫です。」**

| 位置 | 内容 |
|---|---|
| ヒーロー | 川口市の家族葬・直葬なら自社式場の川口典礼へ／めぐりの森まで車5分／駐車場70台／創業20年・累計4,600件超／Googleクチコミ★4.5／アンケート満足度97%超 |

## 2. 専門家討議：どういう訴求ならクリックされるか

### 1. ダイレクトレスポンス設計の視点

**DGは「探していない人の画面」に出る。**検索広告と根本的に違う。
検索広告は「答えを提示する」が、DGは「**自分ごとだと気づかせる**」ことが仕事。

葬儀は発生型の需要なので、バナーを見た瞬間に必要な人はごく一部。
ではクリックするのは誰か。**「いま、まさに困っている人」と「近い将来を意識している人」**の2層だけ。

- 前者には「**いま電話がつながる**」
- 後者には「**まだ決まっていなくてよい**」

**どちらにも効く一文が「まだ何も決まっていなくて、大丈夫です」。**
LPのヒーローがそのまま最良のバナーコピーになっている。

### 2. ご遺族心理の視点

ご逝去直後の方が求めているのは情報ではなく**許可**である。

「病院から早く移動してと言われた」「どこに頼めばいいか分からない」「失礼なことをしていないか不安」。
この状態の人に対して、価格の大きな数字は**判断を迫るもの**として働く。

**「決めなくていい」「まだ何も決まっていなくて大丈夫」は、判断を迫らない唯一のメッセージ。**
バナーで安心させ、電話で受け止める。この順序を崩さない。

> 逆に「88,000円〜」は、**価格で比較する土俵**に自分から乗ることになる。
> 大手ポータルが同じ土俵で全国規模の予算を使っている場所で、当社が勝てる理由がない。

### 3. ディスプレイ広告のクリエイティブの視点

**実際に表示されるサイズは、規定の推奨サイズよりはるかに小さい。**
1200×628 で入稿しても、配信面では 300×157 程度で出ることが多い。

したがって守るべき制約は3つ。

| 制約 | 内容 |
|---|---|
| **主見出しは12文字前後** | それ以上は縮小時に読めない |
| **情報は3つまで** | 主見出し＋補足1行＋数字1〜2個 |
| **コントラストを確保** | 淡い配色は白い画面で沈む。ブランドの深緑 `#1c3a30` を面で使う |

現行のスクエア5枚は、この点では**よくできている**（「車で5分」「70台」「24時間365日」の3情報）。
問題は横長のほうで、価格が主役になっている。

### 4. 景表法・葬儀業界の表示の視点

| 避けるもの | 理由 |
|---|---|
| 「最安」「必ず」「絶対」「追加費用なし」「総額確定」 | `CLAUDE.md` §11・§19.3 の禁止表現 |
| 価格の単独表示 | 条件（会員価格・別途費用）を併記できないサイズでは誤認を招く |
| 「川口市めぐりの森」を自社施設のように見せる表現 | 市営の火葬場。**近接性は言えるが、運営は当社ではない** |
| 実在しない建物を自社式場として見せる | §13 |

**「めぐりの森まで車で約5分」は事実として言える。**「めぐりの森の」とは言わない。

### 5. デザイン（視認性）の視点

- **人物を生成しない。**生成した人物を当社スタッフのように見せることはできない（`docs/operations/2026-09-09-image-generation.md` の「守ること」）。
  現行バナーの女性はモデル写真と思われるが、**生成画像で置き換えるのは筋が悪い**
  → **建物・空間・光・余白**で構成する。葬儀の広告として、むしろこちらが品位に合う
- ブランドカラー（深緑 `#1c3a30`〜`#2a5145`、紙 `#faf8f3`）で統一し、LPを開いたときに**同じ色**が出るようにする
- 緊急色 `#b42318` は電話まわりのみ。面で使わない

### 6. 計測・LP整合の視点

バナーとLPの**言葉を揃える**。クリック直後に同じ言葉が出ると、離脱が減る。

| バナーの主見出し | LPで受ける場所 |
|---|---|
| まだ何も決まっていなくて、大丈夫です | ヒーローの見出し（完全一致） |
| 24時間365日、いまお電話がつながります | ヒーロー直下／電話ボックス |
| めぐりの森まで車5分・駐車場70台 | 選ばれる理由 01・02 |
| 自社式場だから、時間に追われません | 選ばれる理由 03 |

| # | 決めたこと |

| 2 | **価格は一切出さない。** 「88,000円」系は作らない |
| 3 | **人物は生成しない。** 建物・空間・光・余白で構成する |
| 4 | **情報は3つまで。** 主見出し＋補足1行＋数字1〜2個 |

| 6 | **明るい基調にする**（2026-09-12 松澤の指摘）。**背景は温かみのある生成り `#faf8f3`〜淡い緑 `#eef3ef`。文字が深緑 `#1c3a30`。** 深緑を全面に敷いた暗いバナーは作らない |

### 少数意見（取り下げていない）

- **「人物なし」で本当にクリック率が保てるか。** 現行バナーは人物入りで、DGのCTRは1.57%。
  人物を外して落ちる可能性はある。**実写のスタッフ写真が用意できるなら、そちらのほうが強い**
  → 今回は生成で作るため人物なしとするが、**実写が撮れたら差し替えを検討する**
- **「まだ決まっていなくて大丈夫」は緊急層に刺さるか。** 緊急層には「24時間つながる」のほうが直接的。
  → **2つの系統を両方作り、アセット別の成績で判断する**
- **競合と同じ型（緑＋黄色＋価格）のほうがCTRは高いのではないか。** 可能性はある。
  ただし**「最安」は使えず価格でも追わない**方針である以上、同じ型を選んでも中身が伴わない。
  → **当社にしか言えない「自社式場」「火葬場まで車5分」「駐車場70台」で勝負する**

## 4.5 【第2版】松澤の差し戻しを受けた設計変更（2026-09-12）

初版（明朝体・細字・人物なし・淡色）に対し、次の指摘を受けて全面的に作り直した。

> **「見えるか見えないかの文字だと全然訴求が足りない」「人物も入れて良い」「まずインパクトが足りない」**

### 何が間違っていたか

| 初版 | 問題 |
|---|---|
| 細い明朝体 | **DG面では横300px程度に縮小される。細字は消える** |
| 淡い色の文字 | コントラスト不足。**読めない広告は広告として成立しない** |
| 人物なし | 競合2社とも人物を使っている。**顔があると「相談できる相手がいる」が一瞬で伝わる** |
| 余白が主役 | 上品だが**弱い**。静けさと不在は別物 |

**「競合と違う」を追求するあまり、広告として成立する最低条件（読めること）を犠牲にしていた。**
差別化は、可読性を確保したうえでやるもの。

### 第2版の設計

| 項目 | 内容 |
|---|---|
| 書体 | **極太ゴシック**（明朝をやめた） |
| 強調 | 見出しの最も伝えたい一節を**濃い緑の帯に白抜き**。小さくしても必ず読める |
| バッジ | 最上部に**濃い緑の角丸バッジ＋白抜き**で「川口市の家族葬・直葬」 |
| 人物 | **黒いフォーマルスーツの女性スタッフ（40代前後・落ち着いた表情）を右に配置。** 下端に「※写真はイメージです」を必ず入れる |
| 背景 | **明るい生成り＋自然光＋淡い緑**（明るさは維持） |
| 情報量 | バッジ＋主見出し＋補足1行＋社名の4つまで |

**競合との差別化は「色の派手さ」ではなく「言っていること」で取る。**
競合が「最安75,000円〜」と言う場所で、当社は「**まだ何も決まっていなくて、大丈夫です。**」と言う。
デザインの強さは同等、メッセージが真逆。これが正しい差別化。

とくに横長と縦長は上下を切るため、下端の「※写真はイメージです」が残るように調整すること。

### 人物について（重要）

- **「当社のスタッフです」とは言わない**

## 4. コピーの修正：「貸式場ではありません」をやめた

候補1の横長03・スクエア06は主見出しを**「貸式場では、ありません。」**としていたが、
松澤より「この表現が正しいのか。自社ホールや自社式場という言い方の方がよいのでは」と
指摘があり、**候補2では使っていない。**

やめた理由は3つ。

1. **否定文は一瞬では読めない。** 300px に縮小された画面で「〜ではありません」は、
   何を言っているのか分かるまでに時間がかかる。
2. **「貸式場」を知っている人でないと意味が通じない。** 逝去直後の方が
   業界の区分を知っている前提を置くのは無理がある。
3. **他社の業態への当てこすりに読める。** `CLAUDE.md` §15（競合比較ルール）の
   誹謗中傷禁止に照らして、わざわざ選ぶ表現ではない。

**「川口市・新井宿の、自社ホールです。」**という肯定文に置き換えた。
言いたいことは同じで、読む速さと安全性が上がる。
