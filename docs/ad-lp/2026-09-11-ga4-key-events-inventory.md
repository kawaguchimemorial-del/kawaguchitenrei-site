## 6. 切替後の二重計上マトリクス

### 6-1. フォーム送信 → `generate_lead` 1本に統一する（推奨）

**`lp_generate_lead` を主要CVにする必要はない。** `pagePath` だけで LP と本サイトを分けられるため。

実測（90日・`generate_lead` のページ別内訳）：

| ページ | 件数 |
|---|---:|
| `/contact/` | 26 |
| `/lp/` | **6** |
| `/estimate/` | 5 |
| `/lp/contact/` | **2** |

→ **LP分は8件、本サイト分は31件**と、すでに分離できている。

| | 扱い |
|---|---|
| `generate_lead` | **主要CV（1本だけ）**。LP分は `pagePath` が `/lp/` `/lp/contact/` で識別 |
| `lp_generate_lead` | **観測用。主要CVにしない**（同じ行動の二重計上になる） |

> ⚠ **実装上の注意。** `/lp/contact/` のフォーム成功時は、コードが**両方を発火させる設計**になっている
> （`app/lp/contact/LpContactForm.tsx` で `pushGenerateLead("lp_contact")` と
> `trackLpEvent("lp_generate_lead")` を続けて呼ぶ）。
> いまは `lp_generate_lead` が届いていないため二重にならないが、
> **`lp_*` の送出を直した瞬間に、1回の送信で2つのイベントが立つ。**
> だからこそ「主要CVは片方だけ」を先に決めておく必要がある。

> 補足：`form_type` パラメータは送出されているが、**GA4のカスタムディメンションとして未登録**のため
> レポートでは絞り込めない（`customEvent:form_type is not a valid dimension`）。
> `pagePath` で足りるので、登録は必須ではない。

### 6-2. 電話タップの扱い

実測（90日・`click_tel` のページ別内訳）：

```
/ 38 ／ /hall/kawaguchi-memorial-hall/ 16 ／ /plan/ 8 ／ /access/ 5
/plan/hanaire-owakare/ 4 ／ /contact/ 1 ／ /plan/direct-funeral/ 1 ／ /plan/family-funeral/ 1
```

**`/lp/` は `click_tel` を発火しない設計。**電話リンクには `data-lp-event="lp_click_tel"` を付けており、
本サイト用の `click_tel` とは別のイベントになっている。実測でも `/lp/` の `click_tel` は0件。

つまり**電話タップについては、そもそも本サイトとLPが混ざらない。**
問題は `lp_click_tel` が0件＝**届いていない**ことのほうにある。

| | 扱い |
|---|---|
| `click_tel`（本サイト） | 維持。自然検索・直接流入の成果として観測 |
| `lp_click_tel`（`/lp/`） | **まず届くように直す。**そのうえで、タップは実着信ではないので、通話計測（通話レポート／計測用番号）が入るまで主要CVにしない判断もありうる |
| 両者 | **合算しない** |

### 6-3. その他の `lp_*`

`lp_view` `lp_contact_open` `lp_form_start` `lp_plan_open` `lp_directions` は
**すべて観測用。「問い合わせ完了」として扱わない**（手順書の指示どおり）。

## 8. 当社側の推奨（NEXT UP の回答後に確定）

### `/lp/`（広告の着地先）

| 種別 | イベント | 理由 |
|---|---|---|
| **主要CV** | `generate_lead`（`pagePath` が `/lp/` `/lp/contact/`） | 唯一の「送信完了」。すでに動いている |
| 補助（観測） | `lp_click_tel` | タップ≠実着信。通話計測が入ってから昇格を判断 |
| 観測のみ | `lp_view` `lp_contact_open` `lp_form_start` `lp_plan_open` `lp_directions` `lp_generate_lead` | 手順書の指示どおり |

**先に `lp_*` が届くように直すこと（§3）。** 直さないまま切り替えると、補助・観測の指標が全滅する。

### 本サイト（自然検索・直接流入）

| 種別 | イベント | 理由 |
|---|---|---|
| 主要 | `generate_lead`（`/contact/` `/estimate/`） | 送信完了 |
| 補助 | `click_tel` | タップ≠実着信 |
| **見直し候補** | `click_contact_cta` / `click_estimate_cta` | ボタンを押しただけ。**社内資料で問い合わせ件数として扱わない** |

**「キーイベントから外す」と「広告へインポートしない」は別の操作。**
GA4 側はキーイベントのまま観測を続け、**広告側でインポートしないだけ**でもよい。
