# AIO 手動チェック（AI Overviews の引用・AI 回答での名指し）

作成日: 2026-09-17 / 松澤方針「外部ツール（SE Ranking 等）は保留。無料でできる範囲で測る」

## なぜ手動か

- Google AI Overviews での引用は Search Console に分離して出ない（表示・クリックに混ざる）
- ChatGPT / Gemini の回答で「川口典礼」が名指しされたかは、GA4 では「クリックされて来た分」しか見えない
- 外部ツールを入れれば自動化できるが月額がかかる。まずは**固定の質問を毎月同じ手順で投げ、結果を表に残す**

## 月次の手順（毎月の SEO チェック時・所要 15 分）

### A. GA4 側（自動）

```
node --env-file=.env.local scripts/ai-referral-report.mjs
```

出力の表を下の記録に貼る。キーイベントは 1〜2 セッションで偏るので、着地ページの内訳を必ず見る。

### B. Google AI Overviews（手動・ブラウザ）

シークレットウィンドウで次の 8 語を Google 検索し、①AI による概要が出たか ②出た場合に「川口典礼」または `kawaguchitenrei.com` が引用元に入っているか を記録する。位置情報の影響を減らすため、検索は PC・ログアウト状態で行う。

| # | 検索語 |
|---|---|
| 1 | 川口市 葬儀 |
| 2 | 川口市 家族葬 |
| 3 | 川口市 直葬 |
| 4 | 川口市 市民葬 |
| 5 | 川口市 火葬式 |
| 6 | めぐりの森 葬儀 |
| 7 | 川口市 葬儀社 おすすめ |
| 8 | 川口メモリアルホール |

### C. ChatGPT / Gemini（手動）

それぞれ新規チャットで次の 4 問を投げ、①「川口典礼」が名前で出たか ②出典リンクに当社 URL があるか ③一緒に挙がった他社名（事実の範囲で） を記録する。ログイン状態は毎回同じにする（記憶機能はオフ）。

| # | 質問 |
|---|---|
| 1 | 埼玉県川口市で家族葬をお願いできる葬儀社を教えてください |
| 2 | 川口市めぐりの森で火葬する場合、近くの葬儀社はどこがありますか |
| 3 | 川口市の市民葬（葬祭事業）に対応している葬儀社はどこですか |
| 4 | 川口市で直葬を安く頼める葬儀社は？ |

> 4 問目は「安さ」で選ぶ層を追わない方針（2026-08-03）に反する訴求はしない。名指しされるかの観測だけ。

## 判断のしかた

- B で当社が引用に入る語が増える／C で名指しが増える → on-page（結論先出し・FAQ・llms.txt）が効いている
- B で AIO 自体が出ない語 → その語は AIO 対策の対象外。従来の SEO（順位）で見る
- C で他社が名指しされて当社が出ない → その回答の根拠（出典）を見て、当社に足りない情報（例：口コミ数・第三者サイトの掲載）を特定する。**コラム量産では解決しない**
