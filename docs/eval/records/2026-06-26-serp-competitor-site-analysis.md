## 2. 上位がなぜ上か（タイプ別）

### (a) ポータル（soogi / いい葬儀 / 小さなお葬式 / むすびす / ファミーユ 等）
- **ドメイン権威・網羅性・更新頻度・被リンク量**が桁違い。個社サイトが純コンテンツで抜くのは非現実的。
- 「おすすめ」「ランキング」「比較」系はポータルの独壇場 → **このタイプのKWは深追いしない**のが定石。

### (b) 川口市公式（city.kawaguchi.lg.jp）
- 公的機関ドメイン。情報KW（葬祭事業・市民葬・葬祭費）では不動。**勝つ対象でなく、引用・整合の対象**。

### (c) 競合葬儀社：花ぜんセレモニー（最重要・実質の直接競合）
「川口 家族葬」1位・「川口市 葬儀」3位。WebFetch分析でわかった強み：
- **創業60年以上（昭和33年創業）** … 川口典礼（創業20年）より長く、E-E-A-T・地域定着シグナルが強い
- **「JR川口駅東口より徒歩5分」を繰り返し訴求** … 川口の中心＝川口駅前の立地。川口典礼（新井宿・西新井宿＝市の周縁）より「川口」中心地の地理的即時性が高い
- **「川口市の市営葬指定業者」** の権威表記
- **NAP（社名・住所・電話）が一貫**、ローカルKW密度が高い
- 古いドメインで被リンク・歴史的評価が蓄積している可能性

弱点（＝川口典礼が勝てる点）：
- **ブログ/コラムなし**（情報コンテンツが薄い）
- **構造化データ・FAQマークアップが見当たらない**
- 価格の具体額が出ていない（総額表示の方針のみ）

→ **花ぜんは「立地（川口駅前）×老舗×ローカル一貫性」で上位。コンテンツ/構造化データは川口典礼が上。**

## 3. サイト内監査の要点（強み・弱点）

### 強み（既に高水準）
- データ駆動・型安全（areas/plans/halls/columns）。13エリア×11プランで地域×サービス語カバレッジが高い
- 構造化データ網羅（FuneralHome/Service/FAQPage/BreadcrumbList/BlogPosting/Offer/Place）。aggregateRating不使用＝葬儀社として適切
- 結論先出し・FAQ・基本情報表などAIO構造を意図実装。めぐりの森近接訴求は徹底
- title/description/canonical/sitemap/robots は整備済み

### 弱点・改善余地（優先度順）
1. **エリアページ間の相互リンク不足**（兄弟エリア→ハブ等は一部あるが、ハブ＆スポークが不完全）
2. **コラムのAIO最適化が記事により不統一**（結論ボックス/ポイント箇条書きが無い記事あり）
3. **見出し(h1/h2)にKW×地域が弱い**（本文には自然分散だが、見出しレベルで「川口市の葬儀/家族葬」が弱い）
4. **Place(saijo)のJSON-LDが不完全**（営業時間・利用条件など）
5. **legacy URL `/chokusou` が現存しSERPに出ている**（`/plan/direct-funeral/` と内容重複の可能性）→ 正規化/リダイレクト要確認
6. title/descriptionの文字数・記号の不統一（軽微）
