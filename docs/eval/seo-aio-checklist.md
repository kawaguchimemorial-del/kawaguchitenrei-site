# SEO / AIO / UX 評価チェックリスト

このファイルは、改修後にページ品質を評価するためのチェックリスト。
**改修ごとに該当項目を OK / NG / 該当なし で記録** し、リポジトリに残す。

判断軸：`CLAUDE.md` §10、ルール：`docs/01-seo-aio-policy.md` ほか。

使い方：
1. 改修対象ページを決める
2. 該当カテゴリの項目を順に評価
3. NG は理由を「メモ」に書く
4. NG が残ったまま完了報告しない

凡例：
- ✅ OK
- ❌ NG
- ➖ 該当なし

## 記録テンプレート

このチェックリストを使った評価結果は、PR 本文または `docs/eval/records/<日付>-<対象>.md`
に記録することを推奨。

```
日付: 2026-MM-DD
対象: <対象ページ / 改修内容>
チェック結果:
- 通過: <件数>
- NG: <件数>
- 該当なし: <件数>
主な NG とフォロー:
- <項目>: <内容>
次のアクション:
- <内容>
```
