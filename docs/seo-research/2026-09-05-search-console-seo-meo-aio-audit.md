## 6. AIO — 流入はあるが採用率は測れていない

サイトには会社・施設・料金条件・地域ガイド・事例・FAQと構造化データがある。AIが出典として参照するための材料は備わっている。GoogleはAI検索向けにも基本的な検索要件を重視し、特別なAIファイルや専用構造化データを必須にしていない。`llms.txt` の有無を完成度判定の中心に置かない。[GoogleのAI検索に関する説明](https://developers.google.com/search/docs/appearance/ai-features)

GA4の直近28日には `chatgpt.com / ai-assistant` 7セッション・エンゲージメント5・電話タップ9回が記録されていた。9回の内訳はプラン一覧8・トップ1。同じ人の繰り返し操作もあり得るため、9件の実通話や新規依頼と解釈しない。`openai / organic` と `openai / (not set)` は各1セッション。参照元が付かない利用や、AI回答内で読むだけの利用はこの数字に含まれない。

現時点で未測定なのは、質問ごとのAI回答への登場率、公式サイトへの出典リンク率、回答の料金・施設情報の正確性、AI経由の実相談・施行数。GSCのWeb検索集計からGoogleのAI機能だけを分離した数値も今回得ていない。AIが参照しやすい文章を用意したことと、推薦されていることは分けて扱う。

外部紹介サイトにも情報差があった。「つながり」の川口典礼紹介には旧プラン名と正本と異なる価格が残り、追加費用についても広い断定表現がある。外部記事の記載を当社の正しい料金として採用しない。AIが外部の古い情報を参照する可能性があるため、公式サイト・GBP・主要紹介媒体で条件を揃えることを優先候補とする。実際にこのページがAI回答に採用されたことまでは未確認。[確認した外部紹介ページ](https://sougi-lab.com/ranking/saitama-sougisha-ranking/)

## 8. 実装の技術点検

ローカルの本番ビルドHTMLを検査した。エラー用ページとnoindex用途を除いた公開129ページには、title・description・単一canonicalがある。canonicalの完全一致重複は0。JSON-LD 306ブロックはJSONとして解釈できた。これは記法の確認であり、Googleの全ルールへの適合や検索表示を保証しない。

| 項目 | 確認結果 | 優先度・意味 |
|---|---|---|
| 本文の主見出し | 声の詳細30ページでh1なし | 中。意味構造・アクセシビリティを改善。順位低下の原因とは断定しない |
| OG画像 | 51ページでなし。プラン8・事例11・声30・ペット・斎場一覧 | 中〜低。共有プレビューの改善。未登録3件の原因とは断定しない |
| title重複 | 声2ページで同一 | 低。実際の声を尊重し、ページの識別性を検討 |
| エンティティの識別子 | 共通グラフには@idがあり、下位ページの事業者記述には揃っていない例あり | 中。主体の関係と本文との一致を整理 |
| sitemap更新日 | 多くが実行時の日時 | 中。実際の重要更新日を伝えられる設計を検討 |
| HTML量 | 本番トップの非圧縮HTML約1.41 MB | モバイル性能の実測を優先。転送量や表示速度そのものではない |
| 構造化レビュー | URL検査ではトップのレビュー型がPASS | 星表示の資格とは別。自社評価には表示制約がある |

URL検査のリッチリザルト欄は119 URLでPASS、10 URLで判定なし、検出されたエラーは0だった。PASSをAIO採用や星表示の保証には使わない。自社のLocalBusinessの評価は、外部レビューを転載してもGoogleの自社評価制約がある。[レビュー構造化データの公式ガイド](https://developers.google.com/search/docs/appearance/structured-data/review-snippet)

FAQ本文は利用者への説明として有用だが、Googleは2026-05-07にFAQリッチリザルトの表示を終了している。「FAQスキーマを追加すれば検索結果が拡張される」という古い前提は更新する。[Google Searchの変更履歴](https://developers.google.com/search/updates)

PageSpeed Insights APIはトップ・家族葬の2 URLともHTTP 429で、今回の速度スコアとCore Web Vitals実測値は取得できなかった。API制限をサイトの速度エラーと扱わない。モバイルはGSCクリックの約65%を占めるため、性能検査は残す価値がある。

本番配信はVercel応答を確認済み。今回の読み取りツールはローカルからAPIを利用するもので、Vercelの環境変数やデプロイ設定を変更していない。基礎構成の詳細は[前段のサイト分析](2026-09-05-site-baseline-and-codex-handoff.md)を参照。

## 11. 数値の限界

- GSCはWeb検索・確定データ、日付は太平洋時間。GA4はAsia/Tokyo。同じ日付ラベルでも完全な時間範囲一致ではない。
- クエリ集計は匿名化や上位行の制約があり、行がないことは検索需要0を意味しない。サイト単位とページ単位の集計も混ぜない。[Search Analytics API仕様](https://developers.google.com/webmaster-tools/v1/searchanalytics/query)
- GSC/GA4の28日比較とGBPの暦月比較は期間が異なる。比率や件数を直接合算しない。
- URL検査は取得時点でGoogleが保持する情報であり、その後の変化や最新本番内容の評価完了を保証しない。
- GBPのプロフィール順位を複数地点で測ったわけではない。表示・ルート・通話操作は顧客人数や施行数ではない。
- AI流入は参照元が識別できたもの。AIへの露出総数、推薦率、実顧客数の測定は残る。
- 速度・Core Web Vitals、手動対策画面、セキュリティ問題画面の確認は未完了。今回のデータから問題の有無を断定しない。
