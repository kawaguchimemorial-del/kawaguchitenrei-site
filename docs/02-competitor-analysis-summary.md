# 02. 競合分析 要約

このファイルは、川口典礼サイトの SEO / AIO 改善・コンテンツ拡張の参考にするための
競合分析要約。**競合を誹謗中傷せず、事実と公開情報の範囲で整理する**。

詳しい個別調査ノートを将来作る場合は `docs/competitors/<slug>.md` などにサブ整理する。

---

## 1. 対象とカテゴリ分け

| カテゴリ | 例 | 特徴 |
|---|---|---|
| 大手ポータル | 小さなお葬式、よりそうお葬式、イオンのお葬式 | 全国網・低価格訴求・SEO 強・口コミ集約 |
| 互助会系 / 大手葬儀社 | さがみ典礼、セレモニー、小さな森の家 | 会員制・会館多数・地域シェア大 |
| 地元葬儀社 | 花ぜんセレモニー、山崎典礼、あゆみ葬祭、家族葬本舗、葬儀のともしび、南彩会館 | 地域密着・自社式場・対面営業 |

---

## 2. 大手ポータル・大手葬儀社の強み

- **ブランド認知**：TV CM・ネット広告で広く知られる
- **SEO の強さ**：ドメインオーソリティ高、被リンク多数
- **低価格訴求**：「○○円〜」を強く打ち出す
- **全国対応の安心感**：どこでも同じ価格・同じプラン
- **口コミ集約**：施行件数が多く、口コミの量で勝る
- **問い合わせフォーム最適化**：流入後の CV を磨いている

逆に弱い点：
- 実際の式場・スタッフが地域ごとに異なり、品質のばらつきがある
- 紹介手数料モデルが価格に乗っている場合がある
- 自社式場の物理的拠点が薄いケース

---

## 3. 互助会系・大手葬儀社の強み

- **会館の数**：複数の自社会館で広範囲をカバー
- **会員制度**：事前積立・優待で囲い込み
- **施行件数**：地域シェアと運営ノウハウ
- **格式感**：式の進行・接遇の安定感

逆に弱い点：
- 会員制度の説明が難解で、解約・退会の不安を抱かれやすい
- 「会員じゃないと損？」のような疑念を持たれる
- 価格の総額が分かりにくいケース

---

## 4. 地域競合の強み

- **対面の安心感**：担当者の顔が見える
- **地域行事・寺院との関係**
- **菩提寺対応**
- **柔軟な対応**（自宅安置、地域慣習）

逆に弱い点：
- Web 上での情報量が少ないケースが多い
- SEO / AIO の対策が薄い
- 価格表示が不明瞭

---

## 5. 川口典礼が勝てる軸

| 軸 | 訴求 |
|---|---|
| **自社式場** | 川口メモリアルホール（川口市西新井宿）という具体拠点 |
| **火葬場近接** | 川口市めぐりの森まで車で約 5 分 |
| **駐車場 70 台** | ご親族・参列者が安心 |
| **24 時間 365 日** | お電話受付 |
| **創業 20 年・年間約 260 件** | 地域での実績 |
| **市民葬対応** | 川口市の葬祭事業登録業者 |
| **価格の透明性** | 会員価格 / 通常価格を併記、追加費用要素を明示 |
| **個室面会室** | 川口メモリアルホールでゆっくりお別れ |
| **対応形式の幅** | 直葬・花入れお別れ・一日葬・家族葬・一般葬・市民葬 |

これらは大手ポータル・互助会系・地域競合の **いずれにも完全には真似されない複合的な強み**。
コンテンツでは、この複合を 1 ページで体感できるように設計する。

---

## 6. 川口典礼が負けやすい軸

| 負けやすい軸 | 対応方針 |
|---|---|
| **価格の見かけ最安値** | 価格訴求では大手ポータルに対抗しない。「目安」と「総額モデル」で透明性勝負 |
| **会館数の多さ** | 自社式場 1 拠点で勝負しつつ、外部斎場（めぐりの森・戸田・谷塚・寺院会館）対応を明示 |
| **全国ブランド認知** | 地域認知に絞る。川口・新井宿・鳩ヶ谷・近隣の検索で勝つ |
| **広告費** | 広告ではなく、SEO / AIO とコンテンツで持続的に勝つ |
| **Web の情報量** | コラム・FAQ・施工事例・口コミを着実に増やす |

---

## 7. 競合比較時の注意点

- **固有名詞を出すときは、事実・公開情報のみ**
- **優劣の断定はしない**（「○○より安い」「○○より良い」はNG）
- **誹謗中傷は絶対にしない**
- **カテゴリ比較は OK**（「大手ポータル型 vs 地元葬儀社」「互助会型 vs 都度払い型」）
- 比較表を作る場合は、各方式の **長所と短所を両方** 書く
- 「川口典礼の場合」を最後に置く

## 8. 今後作るべき比較検討コンテンツ案

検討フェーズ（情報収集中）のユーザーに刺さる比較・解説コンテンツ。
それぞれ単独で SEO ターゲット記事になり、内部リンクで CTA に繋ぐ。

| タイトル案 | 想定読者 | 中心キーワード |
|---|---|---|
| 川口市で葬儀社を選ぶときのポイント | 初めて葬儀を検討する家族 | 川口 葬儀社 選び方 |
| 大手ポータル型と地元葬儀社の違い | 大手 vs 地元で迷っている人 | 葬儀社 大手 地元 比較 |
| 互助会型と地元葬儀社の違い | 互助会の解約・継続を悩む人 | 互助会 葬儀社 比較 |
| 川口市の家族葬の費用目安 | 費用感を知りたい人 | 川口 家族葬 費用 |
| 川口市めぐりの森を利用する葬儀の流れ | めぐりの森で火葬を予定する人 | めぐりの森 葬儀 流れ |
| 安い葬儀プランを見るときの注意点 | 価格で比較中の人 | 葬儀 プラン 安い 注意 |
| 川口市の市民葬の使い方 | 市民葬を検討する人 | 川口市 市民葬 |
| 直葬・家族葬・一日葬・一般葬の違い | 形式を理解したい人 | 葬儀 種類 違い |
| 葬儀の事前相談で聞いておくこと | 事前相談を検討中 | 葬儀 事前相談 |
| 川口市の寺院会館・民営式場の選び方 | 菩提寺がある人 | 川口 寺院会館 |

書くときの原則：
- **結論先出し**：冒頭 2〜3 行で「結局どう違うか」
- **比較表**：長所・短所両論併記
- **「川口典礼の場合」**：最後に自社の特徴を控えめに置く
- **CTA**：「事前相談」「プラン詳細」「斎場一覧」「お見積り」へ自然に繋ぐ
