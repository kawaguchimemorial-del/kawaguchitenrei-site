1. サマリ

  • 検知 Search Console「レビュー スニペット」で 「項目『itemReviewed』のオブジェクト タイプが無効です」（error）。初検出 2026-06-11、該当 1 件。例示 URL：/voice/oneday-careful-guidance/。
  • 原因 itemReviewed.@type が FuneralHome 単体。schema.org 上は正しい型だが、Google のレビュー スニペットが認める itemReviewed 型のリストに FuneralHome が無い（LocalBusiness / Organization / Product 等のみ対応）。
  • 修正 @type を ["LocalBusiness", "FuneralHome"] の配列に変更。Google は先頭の LocalBusiness を認識しエラー解消、FuneralHome の具体性（AIO 向け）も保持。
  • 検証 npm run build 成功・voice 全 30 ページ含め静的生成維持。

2. 原因の詳細

Google のレビュー スニペット（review snippet）リッチリザルトは、itemReviewed に指定できる型を限定列挙している（Book / Course / Event / LocalBusiness / Movie / Organization / Product / Recipe / SoftwareApplication など）。

FuneralHome は schema.org では LocalBusiness のサブタイプだが、Google の検証器はサブタイプを解決せず、列挙にない型＝「オブジェクト タイプが無効」として弾く。これがエラーの直接原因。

3. 変更内容

ファイル変更
app/voice/[slug]/page.tsx itemReviewed.@type："FuneralHome" → ["LocalBusiness", "FuneralHome"]（意図コメント追記） 
// before
itemReviewed: {
  "@type": "FuneralHome",
  ...
}

// after
itemReviewed: {
  // Google のレビュー スニペットが認める型は LocalBusiness 等に限られ、
  // サブタイプの FuneralHome 単体だと「itemReviewed のオブジェクト型が無効」になる。
  // LocalBusiness を先頭に置きつつ FuneralHome の具体性も残す。
  "@type": ["LocalBusiness", "FuneralHome"],
  ...
}

このブロックは /voice/[slug] の共通テンプレート。修正は voice 詳細 全 30 ページに反映される。

  1. Vercel 本番デプロイ完了を待つ。

  3. Google リッチリザルト テストで「レビュー スニペット」が有効判定になることを確認。
  4. 確認後、Search Console の「修正を完了しましたか？」→ 検証を開始（再クロール依頼）。
