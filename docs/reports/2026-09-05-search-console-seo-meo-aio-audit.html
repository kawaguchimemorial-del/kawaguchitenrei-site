5. MEO — Googleマップと管理画面の確認

既存ログインのあるEdgeから、対象のGoogleマップ →「ビジネス プロフィールを管理」→「パフォーマンス」を読み取った。APIはHTTP 429・割り当て0だったが、プロフィールは掲載中で、ブラウザ管理画面は閲覧できた。API制限とマップ掲載・管理権限は別である。

公開名は「株式会社川口典礼 川口メモリアルホール」、表示カテゴリは葬儀屋。所在地・電話・公式サイトリンク・24時間営業はサイト側と整合した。Google評価は4.5・28件で、オーナー返信も表示された。サイト側の lib/company.ts と lib/reviews.ts は27件の記録で、1件の更新差がある。口コミ件数だけを機械的に更新せず、集計日・対象を合わせる。確認したGoogleマップ

商品情報に価格差を発見した。 Googleの商品欄では一日葬プランが469,000円。正本の通常価格は496,000円、事前相談会員価格は396,000円で、どちらとも一致しない。商品詳細を開いても469,000円と表示され、説明内の会員価格396,000円は正本と一致していた。他の表示例は直葬189,000円、花入れ279,000円、家族葬628,000円、夕暮れ551,000円、市民葬231,000円で、それぞれ正本の通常価格または市民価格と一致する。「サイトは会員価格、GBPは通常価格」という違い自体を誤りと扱わず、一日葬の不一致を優先して確認・訂正する。

概要で表示されたオーナー最新投稿は2026-07-30の夕暮れ家族葬案内。説明文には面会について広い表現があり、面会を行わないシンプル直葬などの条件と矛盾しない案内かを確認したい。投稿数や頻度だけで順位上昇を約束することはできない。

6. AIO — 流入はあるが採用率は測れていない

サイトには会社・施設・料金条件・地域ガイド・事例・FAQと構造化データがある。AIが出典として参照するための材料は備わっている。GoogleはAI検索向けにも基本的な検索要件を重視し、特別なAIファイルや専用構造化データを必須にしていない。llms.txt の有無を完成度判定の中心に置かない。GoogleのAI検索に関する説明

GA4の直近28日には chatgpt.com / ai-assistant 7セッション・エンゲージメント5・電話タップ9回が記録されていた。9回の内訳はプラン一覧8・トップ1。同じ人の繰り返し操作もあり得るため、9件の実通話や新規依頼と解釈しない。openai / organic と openai / (not set) は各1セッション。参照元が付かない利用や、AI回答内で読むだけの利用はこの数字に含まれない。

現時点で未測定なのは、質問ごとのAI回答への登場率、公式サイトへの出典リンク率、回答の料金・施設情報の正確性、AI経由の実相談・施行数。GSCのWeb検索集計からGoogleのAI機能だけを分離した数値も今回得ていない。AIが参照しやすい文章を用意したことと、推薦されていることは分けて扱う。

外部紹介サイトにも情報差があった。「つながり」の川口典礼紹介には旧プラン名と正本と異なる価格が残り、追加費用についても広い断定表現がある。外部記事の記載を当社の正しい料金として採用しない。AIが外部の古い情報を参照する可能性があるため、公式サイト・GBP・主要紹介媒体で条件を揃えることを優先候補とする。実際にこのページがAI回答に採用されたことまでは未確認。確認した外部紹介ページ

8. 実装の技術点検

ローカルの本番ビルドHTMLを検査した。エラー用ページとnoindex用途を除いた公開129ページには、title・description・単一canonicalがある。canonicalの完全一致重複は0。JSON-LD 306ブロックはJSONとして解釈できた。これは記法の確認であり、Googleの全ルールへの適合や検索表示を保証しない。

11. 数値の限界

  • GSCはWeb検索・確定データ、日付は太平洋時間。GA4はAsia/Tokyo。同じ日付ラベルでも完全な時間範囲一致ではない。
  • クエリ集計は匿名化や上位行の制約があり、行がないことは検索需要0を意味しない。サイト単位とページ単位の集計も混ぜない。Search Analytics API仕様
  • GSC/GA4の28日比較とGBPの暦月比較は期間が異なる。比率や件数を直接合算しない。
  • URL検査は取得時点でGoogleが保持する情報であり、その後の変化や最新本番内容の評価完了を保証しない。
  • GBPのプロフィール順位を複数地点で測ったわけではない。表示・ルート・通話操作は顧客人数や施行数ではない。
  • AI流入は参照元が識別できたもの。AIへの露出総数、推薦率、実顧客数の測定は残る。
  • 速度・Core Web Vitals、手動対策画面、セキュリティ問題画面の確認は未完了。今回のデータから問題の有無を断定しない。
