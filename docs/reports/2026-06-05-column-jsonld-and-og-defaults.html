2. 仕様確認（Next の metadata マージ挙動）

Next 同梱ドキュメント（generate-metadata「Inheriting fields」）で確認：metadata は浅くマージされ、openGraph は子セグメントが定義すると親を丸ごと上書き、未定義なら親を丸ごと継承。og:title は title から自動補完されない。

→ そのため layout の og 既定には title/description（ブランド既定値）も含めた。これにより自前 og を持たない13ページに有効なブランドOGカードが付与され、自前 og を持つページ（area / plan詳細 / column詳細 等）は影響を受けない。

3. 変更内容

ファイル内容
app/layout.tsxルート metadata に openGraph 既定（type:website / locale:ja_JP / siteName / url / title / description / 既定画像 hall-exterior）を追加。title/description は定数化。
app/column/[slug]/page.tsxホーム→コラム→記事 の BreadcrumbList を追加し、既存 BlogPosting と併せて2つの JSON-LD を出力。
app/column/page.tsxホーム→コラム の BreadcrumbList と、全記事を列挙する ItemList を追加。一覧ページ自前の openGraph（コラム一覧タイトル＋既定画像）も付与。
