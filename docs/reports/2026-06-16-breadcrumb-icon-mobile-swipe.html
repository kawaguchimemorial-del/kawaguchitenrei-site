Breadcrumbs アイコンSVG化＋Cases/Voices のモバイルスワイプ閲覧

作成日：2026-06-16対象：Breadcrumbs / ホーム Cases・Voices担当：Claude Code

アイコン体系の最後の取りこぼし（パンくず区切り）と、自動マーキーのモバイル操作性改善。個人情報・秘密情報なし。

1. 変更内容

項目ファイル変更
① パンくず区切りのSVG化common/Breadcrumbs.tsx区切りの絵文字 › を ChevronRightIcon に置換。全下層ページのパンくずでアイコン体系が統一。リンクのコントラスト（前回 text-ink-mid 化）は維持
② モバイルのスワイプ閲覧home/CasesSection.tsx / VoicesSection.tsx従来は全幅で自動マーキーのみ（モバイルでは止められず送れない）。モバイル(md未満)を scroll-snap の横スクロールに変更し、指でカードを送れるように。PC(md以上)は従来の自動マーキーを維持（ホバー一時停止・prefers-reduced-motion 停止）

2. ②の実装メモ

  • モバイル：flex overflow-x-auto snap-x snap-mandatory ＋各カード snap-start。スクロールバーは [scrollbar-width:none] 等で非表示。次カードが少し覗くことで「送れる」ことが伝わる。下に控えめな案内文「← スワイプで…→」を追加。
  • PC：hidden md:block で従来の .marquee（件数比例の animationDuration）を維持。
  • マーキー複製カードの aria-hidden / tabIndex=-1 はPC側のみ。モバイルは単一セットで読み上げ・キーボード操作とも自然。
  • 「すべて見る／もっと見る」への動線は従来どおり維持。

3. 確認結果

  • npm run build 成功・TypeScript エラーなし。
  • 静的生成 135/135 ページ・増減なし（§19.3 クリア）。

影響範囲：パンくずの区切りアイコン（全下層ページ）と、Cases/Voices のモバイル操作性。構造（URL/title/canonical）・価格・フォーム・共通chrome に変更なし＝SEO 影響なし。
