1. 争点：原因は「順位が低いこと」か

① GSCデータ分析（順位主因説を否定）

否定します。90日データが答えを出しています。7月の平均8.03位でCTR 0.18%、8月の11.52位で0.09%。3.5順位分の差でクリックは3件と1件——母数が小さすぎて有意差とすら言えません。もし順位が主因なら、8位のときにまとまったクリックが出ているはずですが、出ていない。順位を戻す施策は、この語に関して費用対効果がありません。

② SERP構造（①に賛成・理由を補強）

①に同意し、理由を足します。C表の比較が決定的です。同じ7〜10位帯で、情報クエリ（訃報系）は1.3〜2.2%、地域×商用クエリは0〜0.09%。順位帯が同じでCTRが20倍違うなら、変数は順位ではありません。地域×商用SERPには地図枠・広告・ポータルの巨大なブロックが乗り、オーガニック9位は物理的に画面のはるか下です。訃報系のSERPにはそれがない。

③ 計測仕様（①②に部分的に反論）

結論には賛成ですが、論拠の一部は危ういと指摘します。GSCの「平均順位」は表示回数の加重平均で、2ページ目以降の表示も含みます。平均9.1位という数字は「常に9位」を意味せず、5位の日と20位の日の混合かもしれない。つまり①の「8位でもクリックが出ない」は、正確には「8位相当の混合状態でも出ない」です。
それでも結論は変わりません。むしろ混合であるなら、実際にはもっと下に出ている表示が多いということで、②の説明を強めます。

④ ローカルSEO（別の主因を主張）

②③に賛成したうえで、主因をさらに1段絞ります。ローカルパックです。「川口市 葬儀」は Google が明確にローカル意図と判定するクエリで、モバイルではファーストビューがほぼ地図枠で埋まります。E表を見てください。モバイル670表示で0クリック、デスクトップ471表示で1クリック。モバイルのほうが順位は良い（10.23位 vs 13.34位）のにクリックはゼロ。順位が良いほうがクリックされていない——これはオーガニック枠が見られていないことの証拠です。

⑤ ブランド／指名検索（④に賛成・最強の証拠を提示）

④が正しいことは、D表がもっと単純に示しています。「川口典礼」で1.01位、なのにCTR 20.97%。自社名を打ち込んだ人ですら、8割は当社のオーガニックリンクを踏んでいない。地図枠・ナレッジパネルで電話番号と地図が完結するからです。
指名検索でこうなっているのに、地域一般語で「9位を8位にすればクリックが増える」と期待するのは筋が通りません。

⑥ 技術SEO（⑤に一部反論）

⑤の20.97%は、地図枠だけが理由とは限りません。指名検索の一部はブラウザの履歴・ブックマークから直接到達し、検索結果を表示だけして離脱します。GA4の (direct) 50セッションはその一部でしょう。20.97%という数字の解釈には幅を持たせるべきです。
ただし「オーガニック枠が読まれていない」という方向性そのものには反対しません。

争点1の合議（順位主因説：賛成3・反対12 → 棄却）

「川口市 葬儀」のクリックが出ない主因は順位ではない。90日で平均8.03位のときもCTR 0.18%だった事実、同順位帯の情報クエリと20倍の差がある事実、モバイルのほうが順位が良いのにクリックがゼロという事実の3点で確定とする。
ただし③の指摘を採用し、「平均順位は加重平均であり、実際の表示位置には幅がある」ことを前提として明記する。

2. 争点：ではGBP（地図枠）に投資すべきか

⑦ GBP運用（賛成・最優先と主張）

投資先はGBP一択です。F表のSERPで、当社がポータル4本を抜いてオーガニック1〜3位に入る現実的な道筋はありません。相手はドメイン規模で桁が違う。一方、地図枠は川口市内という物理的に閉じた土俵で、そこは大手ポータルが入れない領域です。8/07 の花ぜん分析で「差は立地と地図枠」と結論した内容と完全に一致します。

⑧ 事業判断／ROI（⑦に条件つき賛成）

方向は賛成ですが、期待値は冷静に置くべきです。「川口市 葬儀」は90日で4,044表示・6クリック。仮に地図枠を取ってCTRが1%まで上がっても、90日で40クリック＝月13クリックです。そこから問い合わせに至るのは1件あるかどうか。
この語を「当社最大の需要」と呼んできましたが、それは表示回数が最大なだけで、獲得数が最大とは限らない。GBPに投資する理由は「川口市 葬儀」の40クリックではなく、地図枠経由の電話（サイトを経由しない流入）にあるはずです。そこはGA4にもGSCにも出てきません。

⑨ 消費者心理（⑧を補強）

⑧の指摘は本質です。ご逝去直後の方は「比較検討してからサイトを読む」のではなく、地図で近い順に見て、そのまま電話します。鎌倉新書の調査でも相見積もりを取らない層が大半です。この行動様式では、オーガニック7位のリンクは最初から候補に入らない。
逆に言えば、当社にとっての勝ち筋は「読ませて選ばれる」ではなく「地図に出て、レビューで安心されて、電話される」です。

⑩ 広告運用（⑦に反対・優先順位を争う）

GBPの重要性は認めますが、「一択」には反対します。GBPはAPI承認待ちで、こちらから進捗を動かせない（ケース 8-8661000041490、承認確認は9/01以降）。承認されなければ手が止まります。動かせないものを最優先と呼ぶのは計画として弱い。
また、当社は緊急層向けに広告を出しており、地図枠と広告枠は同じSERPの上半分を争っています。「オーガニックで届かない」という今回の結論は、広告の役割が想定より重いことも同時に意味します。

⑪ 費用対効果（⑩に反論）

⑩には反対です。指名KWのCPCは ¥1,528 → ¥3,444 と上昇中で、競合が指名出稿している状況です。ここで「オーガニックが届かないから広告を厚く」と判断すると、もっとも高い枠を、もっとも高い時期に買い増すことになります。8月に「安い層は獲りにいかない」と決めた判断とも整合しません。
GBPが待ちなのはそのとおりですが、待ちの間にできること（レビュー依頼の運用、写真・投稿の更新、営業時間・属性の整備）はAPI承認がなくても手作業でできます。

争点2の合議（GBP最優先：賛成11・条件つき2・反対2 → 採用、ただし期待値を修正）

投資先はGBPとする。ただし⑧の指摘を受け、目的を「川口市 葬儀のクリック増」に置かない。目的は地図枠経由の直接の電話であり、その成果はGSC・GA4には現れない。効果測定はGBPのインサイト（通話数・ルート検索数）で行う。
API承認待ちの期間も、レビュー依頼の運用・写真・投稿・属性整備は手作業で進められるため停止しない。広告の増額はしない（⑪採用）。

3. 争点：スニペット（title / description）改修に意味はあるか

⑫ スニペット設計（改修すべき）

意味はあります。G表の description は156文字で、日本語モバイルSERPに表示されるのはおよそ前半3分の1です。実際に読まれるのは「川口市めぐりの森まで車で約5分、駐車場70台の自社式場・川口メモリアルホール。」まで。
これは「川口市 葬儀」で探している人への答えになっていません。火葬場までの距離と駐車場台数は、社名を知っている人には効きますが、7位のリンクを踏むかどうかを決める一文としては弱い。冒頭に置くべきは「川口市の葬儀社」「24時間365日」「自社式場」の3点です。

⑬ 検索意図（⑫に部分反論）

診断は正しいが、期待効果を過大に見ています。7位のスニペットは、そもそも読まれていない——それが争点1の結論でした。読まれていないものの文面を直しても、CTRは0.09%から0.3%になる程度でしょう。表示1,114に対して2〜3クリックの増加です。
ただしやらない理由もありません。作業は1ファイル・数行で、リスクはほぼゼロ。「効果は小さいが費用も小さい」案件として扱うべきで、優先順位1位に置くのは誤りです。

⑭ コンテンツ／E-E-A-T（別の観点）

⑫⑬に加えて指摘します。title は「川口市の葬儀・葬儀社なら川口典礼 | 創業20年・24時間365日対応」で、これ自体は良い。問題はポータル4社と並んだときの見え方です。ポータルは「45件」「ランキング」「費用相場」と、選択肢の多さを打ち出します。1社である当社が同じ土俵で戦うと必ず見劣りする。
差別化できるのは「自社式場を持つ地元1社」という点です。スニペットの冒頭は、比較の土俵から降りて、この一点に絞るべきです。

⑥ 技術SEO／パフォーマンス（争点そのものに異議）

スニペット以前に、実測で見過ごせない数字があります。トップページのHTMLが 1,381 KB。通常のNext.jsサイトの5〜10倍で、モバイル回線では初期表示に影響します。
ただし正直に言えば、これは今回の争点の原因ではありません。ページ重量はクリック後の体験に効くもので、クリックされるかどうかには効かない。Googleの評価を通じた間接的な影響はありうるが、CTR 0.05% の説明にはならない。別件として起票すべきで、この討議で対策に混ぜるべきではないと考えます。

争点3の合議（スニペット改修：賛成13・反対0・保留2 → 実施。ただし優先順位は3位）

meta description の冒頭を「川口市の葬儀社」「24時間365日」「自社式場を持つ地元1社」に組み替える。火葬場までの距離・駐車場台数・価格は後半に送る。期待効果はCTR 0.09%→0.3%程度で、クリック数にして月2〜3件と見積もる。過大な期待はしない。
HTML 1,381KB は本件の原因ではないため、別件として起票し、今回の対策には含めない（⑥の申告どおり）。

4. 争点：受け皿はトップページのままでよいか

⑬ 検索意図／情報設計（トップページ維持に反対）

異議があります。A表の4クエリはすべてトップページが受け皿ですが、トップページは「川口市 葬儀」専用のページではありません。h1 は「川口市・新井宿で家族葬・直葬をお考えの方へ。」で、指名・式場・プラン・エリアすべての入口を兼ねています。1ページで全部を受けると、どのクエリに対しても最適ではなくなる。

⑭ コンテンツ／カニバリゼーション（⑬に強く反対）

反対します。7月にカニバリ解消をやったばかりです（10専門家討議・2026-07-14）。ここで「川口市 葬儀」専用ページを新設すれば、トップページと新ページで同じ語を食い合い、7月に片づけた問題を自分で作り直すことになります。
加えて、8/10 に「ページ量産は頭打ち」と結論しています。コラム34本中23本・エリア16本全部がクリック0で、1ページの /hall/ が38クリック。ページを増やす方向はすでに否定された選択肢です。

④ ローカルSEO（⑭を補強しつつ例外を指摘）

⑭に賛成。ただし1点だけ切り分けが必要です。「川口市 家族葬」は20.9位で、他の3語（9〜11位）とは状況が違います。20位台は「SERPに埋もれている」のではなく「単純に順位が足りていない」。この語だけは順位改善の余地が実際にあり、争点1の結論（順位は主因でない）を機械的に当てはめるべきではありません。
9月初旬に予定している受け皿交代は、予定どおり進める価値があります。

⑮ AI検索／AIO（別経路を提示）

受け皿論とは別に、経路の話をします。GA4で chatgpt.com / ai-assistant は3週で 2 → 4 → 2 セッションと小さいものの、キーイベント率が異常に高い週がありました。AI経由の訪問者は、地図枠にもポータルにも邪魔されずに当社へ到達します。
「川口市 葬儀」のオーガニック枠が構造的に取れないなら、AIに引用される形式（結論先出し・基本情報表・FAQ・構造化データ）を厚くするほうが、同じ工数で効く可能性がある。CLAUDE.md §10.3 の3軸のうち「AIに引用される」が、いま相対的に有望です。

⑧ 事業判断／ROI（⑮に反論）

⑮の方向は否定しませんが、母数が2〜4セッションです。ここから施策の優先順位を決めるのは早い。当社サイトは既にFAQ・構造化データ・結論先出しを一巡して実装済みで（on-page は完成済みという6月の評価）、追加でできることは多くありません。観測は続けるが、投資先とはしないのが妥当です。

争点4の合議（受け皿変更：賛成2・反対13 → 否決）

「川口市 葬儀」専用ページは作らない。7月のカニバリ解消と8/10 のページ量産頭打ちの結論を覆す理由が、今回のデータからは出ていない。受け皿はトップページのまま維持する。
例外として「川口市 家族葬」（20.9位）だけは別問題として扱い、9月初旬の受け皿交代は予定どおり進める。AI経由は観測継続・投資はしない（⑧採用）。
