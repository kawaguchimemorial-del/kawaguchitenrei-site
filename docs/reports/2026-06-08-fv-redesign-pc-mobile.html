トップFVリニューアル（PC全幅レイアウト＋デバイス別の実写画像）

作成日：2026-06-08 担当：Claude Code

社内記録（Web非公開・noindex）。個人情報・秘密情報なし。FV／価格表現に該当するため §19.2 により差分・プレビュー提示のうえ人間承認を得て push。

概要：PCのファーストビューを「文字 → 全幅画像 → CTA×2」の縦構成にリニューアル。ヒーロー画像をデバイス別の実写合成（外観＋祭壇）に変更し、PCは横長・モバイルは縦長で最適化。5視点レビュー＋ローカルプレビュー（:3100）で確認のうえ反映。

1. 変更点

項目内容
PCレイアウト従来の2カラム（左:文字／右:縦画像）から、文字（中央）→ 全幅画像 → 電話/事前相談の2CTA の縦構成へ。画像高さは clamp(260px,42vh,460px) でCTAを折り返し内に収め、object-position 40% で看板が残るよう調整。
ヒーロー画像デバイス別の実写合成に変更。PC＝hall-fv-pc.png（横・外観＋祭壇）、モバイル＝hall-fv-mobile.png（縦・外観＋祭壇）。いずれも自社施設の実写。
モバイル従来の画像先行型レイアウトは維持しつつ、画像を縦合成に差し替え（aspect 9:16）。
維持価格1行（直葬139,000円〜・税込）・信頼ポイント・E-E-A-Tバッジ帯・2導線CTA（電話＋事前相談・LINEなし）。h1はモバイル側の1つのみ（PC見出しはp）。

2. 画像選定の経緯（5視点レビュー）

「会館の横長単写真」「修正前の縦合成」「会館＋祭壇の横合成」などを、ご遺族／UX／SEO・E-E-A-T／ブランド／コンプラの5視点で比較。最終的に「実在の会館＋葬儀社だと一目で分かる祭壇」を両立し、かつデバイス別に最適化した実写合成（PC横・モバイル縦）を採用。

3. 方針順守

  • 価格（§9/§14）：正本のみ・税込明記・断定なし。
  • 画像（§12/§13）：自社施設の実写。遺影・個人の写り込みがないことを人間確認済み。素材サイトのモデル写真は不採用。
  • トーン（§3/§4/§5）：配色・2導線CTA・共通レイアウト（Header/Footer/MobileBottomCTA）は不変。
  • §19.2：FV／価格に該当 → 差分・プレビュー提示のうえ人間承認を取得して push。
