area テンプレの絵文字アイコンをSVGへ統一（横展開①）

作成日：2026-06-16対象：area テンプレ担当：Claude Code

「コンセプトは変えず、磨き込みを他テンプレへ横展開」方針の第一弾。地域SEO最優先（§7）の area から。個人情報・秘密情報なし。

1. 内容

トップ・共通chrome・コラム・声で実施済みの「絵文字→共通SVGアイコン」統一を、area テンプレ全体に横展開。OS依存の絵文字（→ ☎ 等）を @/components/common/icons の SVG（ArrowRightIcon / PhoneIcon ほか）に置換。

  • 対象：共有コンポーネント5本（AreaDetailMain / AreaDetailCta / AreaDetailIntro / AreaDetailExtras / AreaPrimaryHall）＋エリアページ16本（app/area/page.tsx＋各エリア15本）＝計21ファイル・約30グリフ。
  • サイズ方針：本文中矢印 h-4 w-4、電話アイコンは元のサイズに応じて h-6/h-7。色クラスは保持。
  • FAQの Q./A./+、装飾の ※ は対象外（UIアイコンではない）。

2. 確認結果（独立検証）

  • area 配下の aria-hidden 内 UIグリフ（→ ☎ ✓ › ↗ ←）残存＝0。
  • 21ファイル全てに @/components/common/icons の import あり。抜き取り目視（AreaDetailCta・aoki）で正常。
  • npm run build 成功・静的生成 135/135 維持。

影響範囲：アイコンの字形統一（見た目のみ）。構造・URL・title・価格・式場可否・フォームに変更なし＝SEO影響なし。
