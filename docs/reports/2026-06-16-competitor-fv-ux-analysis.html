川口エリア 上位葬儀サイトの FV/UX 分析と、kawaguchitenrei.com に足りないもの

作成日：2026-06-16対象：競合・ポータル約20サイト担当：Claude Code

「川口 葬儀」関連で kawaguchitenrei.com より上位に出る競合群の FV（ファーストビュー）と UX を調査し、自社の不足点を抽出。個人情報・秘密情報なし。

調査方法と限界：ポータル/チェーン/地場の約20サイトを4分担で取得・分析。個別の数値・年数・キャッチコピーには取得時の誤差があり得る（一部はJSレンダリングで本文未取得）。ただし20サイト横断で一致したパターンは信頼度が高いため、本レポートは「個社の数字」ではなく「共通パターン」を根拠に結論を出す。

2. kawaguchitenrei.com が“すでに競合と同等以上”の点

不足だけでなく、すでに強い部分を明確化する（むやみに真似て崩さないため）。

  • 所有トラスト指標が厚い：創業20年／年間約260件／駐車場70台／めぐりの森 車5分／葬祭ディレクター在籍／市民葬登録 ＝ 多くの地場競合より情報量が多い。
  • 価格は提示済み：直葬 139,000円〜（PCの信頼ポイント）。プラン5種は会員/通常の二段で透明。
  • 自社式場＋駐車場70台：駐車場を持たない競合に対する明確な差別化（地名・車移動が中心の立地と整合）。
  • お客様の声（アンケート画像＋星）・施行事例：社会的証明の“素材”は保有（FVへの集約が弱いだけ）。
  • エリアページSEOの厚み：/area/* 多数。多くの地場競合より地域ロングテール構造が強い。
  • 落ち着いた作り込み：今回のP1/P2でアイコン・タイポ・余白を統一済。イラスト/テキスト主体の競合より“読み物”の質は上。

4. 結論（FV まわりの打ち手）

  1. FVを実写に置換（P1）＝最優先。合成は競合水準を下回る。手持ちの 建物.png（PC）＋暖色室内（モバイル）で即解消できる。＝今まさに検討中の施策が、競合分析でも“最大の差”として裏づけられた。
  2. FV直下に「結論先出しの帯」：価格の最低ライン＋実績（年数/件数）＋（あれば）口コミ評価を、結論先出しで1列に。素材は保有しているので“集約”するだけ。
  3. 「ご危篤・お急ぎの方へ」の一文をヒーロー内に（電話の近く）。危機段階のユーザーへの配慮（§8）と整合。

やってはいけない真似：満足度%・★・口コミ件数は実データが無いまま載せない（禁止表現・捏造）。Review/aggregateRating の構造化データは §19.2（push 承認要）。価格は §9 正本のみ。煽り（最安/必ず 等）は §11 で禁止。競合が多用する「最安」訴求には追随しない。

5. 次アクション候補

  • P1 FV 実写化のプロトタイプ（PC=建物.png／モバイル=室内 or 4:5比率）。Before/After 提示。
  • P2 FV直下「結論帯」（価格最低ライン＋創業20年＋年間260件）。実データのある“声”の件数があれば併記。
  • P2 既存 column の CTA funnel 強化（特に川口市×補助金/費用相場/手続き）。
  • P3 料金ミニストリップ／資料請求導線（フォーム改修は承認後）。
