D. 情報コラムの導線整流（lib/columns.ts）

問題は「コラムが集客しているのにCVが0」ではなく、導線の置き場所だった。/column/fuhou/・/column/shinsiki/・/column/kenshi-nagare/・/column/shibou-todoke/ の4記事は、 記事の11〜14%地点（＝本文が始まる前）で商用ページへの関連リンクを提示していた。訃報の返信文例を探して来た読者に、読む前から式場・プランを提示する形になっており、CLAUDE.md §11「押し売り禁止」の趣旨からも外れる。GA4 の scroll イベント −33% とも整合する。

実施内容：4記事とも冒頭の関連リンクブロックを削除し、本文末尾（まとめの直後・最終CTAの直前）へ移設。あわせて「情報 → 情報 → 地域」の順に並べ替えた。
  • /column/fuhou/（10,907imp）→ 続けて読む：死亡届 → 川口市の葬儀ガイド
  • /column/kenshi-nagare/（6,084imp）→ 死亡届 → めぐりの森 → 直葬 → 火葬式
  • /column/shibou-todoke/（1,227imp）→ 川口市の葬儀ガイド → めぐりの森 → 直葬
  • /column/shinsiki/（1,967imp）→ 川口市の葬儀ガイド → 家族葬の費用と人数の目安
既に末尾配置だった /column/yujinso-sokagakkai/（92%地点）はその配置を正とし、ラベルのみ統一。CTAは従来どおり末尾1箇所で、追加・増設はしていない。
