3. 原因の分析

① 【最有力・要対応】自社ブランドが3つのドメインに分散し、互いに枠を奪い合っている

「川口メモリアルホール」「川口典礼」で検索すると、自社関連のドメインが3つ出てくる状態になっている。

① 追記・一部訂正【2026-08-07 追加調査】旧サイトは既に機能停止していた／ただし別の緊急案件が判明

松澤より「www.kawaguchi-tenrei.com は昔のサイトで、ドメインもパスワードも分からない」との情報を受け、追加調査を行った。 結果、上記①の見立てのうち2点を訂正する。

訂正1：旧サイトは全アクセスに 403 を返しており、実質すでに停止している

Googlebot に対しても 403 を返しているということは、これは特定UAを弾いているのではなくサイトそのものが表示できない状態である。 Google検索結果に出ているのは過去のインデックスが残っているだけで、403が続けば時間とともに検索結果からも落ちていく。
したがって、旧サイトを「川口メモリアルホール」下落の主因と見るのは無理がある。 §3-① の主因は kawaguchi-memorial-hall.com（Xserver上で正常稼働・HTTP 200・インデックス制御なし）に絞るのが妥当。 旧サイトはSERPの枠を一時的に占めている残骸にすぎない。

訂正2：電話番号・価格の件は、ポータル側の独自表記である可能性が高い

ポータル soogi.jp を確認したところ、公式サイトURLとして正しく https://kawaguchitenrei.com/ を掲載しており、 電話番号は 050-5231-1778——これはポータル各社が使う転送・計測用番号の典型である。 0120-541-710 も同種の番号と考えるのが自然で、旧サイト由来と決めつけるべきではない。前回の書き方は訂正する。 価格帯（13万円〜等）も同様にポータル側の独自記載の可能性が高い。

  • 「【公式】川口メモリアルホール(川口典礼)」というタイトルで検索結果に出ていた実績がある
  • 葬儀業界は競合が多く、ブランド名入りの中古ドメインは狙われやすい
  • 取得されると、「公式」を名乗っていた枠がそのまま第三者のものになる

「放置して自然に消えるのを待つ」は、この場合むしろ危険な選択肢になりうる。

② 【併発】指名検索の需要そのものが減っている（季節性）

「川口典礼」は順位が1.00→1.05でほぼ変化していないのに、表示が64→39、クリックが18→8に減った。 順位で負けたのではなく、検索する人が減ったということ。

  • 8/1（土）4クリック・8/2（日）2クリック と、週末が構造的に低い
  • 8月上旬はお盆前で、葬儀関連の検索需要が動きにくい時期

これはサイト側で対処できる性質のものではない。8月後半〜9月の推移で自然に戻るかを確認する。

③ 【小】コラム系の全般的な微減

訃報返信・検視・創価学会・神道系がそろって1〜2位分下がっている（9〜10位 → 10〜12位）。 特定ページの問題ではなく広く薄く下がっているため、Googleのアルゴリズム変動の可能性が高い。
ただしもともとCTR 0.3%以下の位置なので、クリックへの影響はほぼない。 この帯は「順位を守る」より「5位圏内に押し上げる」以外に改善策がなく、8/3のレポートと同じ結論になる。

4. サイト側の不具合は見つからなかった（否定材料）

下落の原因としてまず疑うべき技術要因を確認したが、いずれも問題なし。
  • 主要ページ全て HTTP 200（/・/hall/kawaguchi-memorial-hall/・/company/・/access/・/column/）
  • sitemap.xml 129 URL（8/3時点と同数・減少なし）
  • コード変更は 7/29 の祭壇画像差し替えが最後。7/30以降のコミットは docs/ のみで、ページには一切触れていない
  • 画像肥大化の影響もなし：元PNGは1.9〜2.5MBあるが、Next/Image が正常に効いており実配信は144KB。 しかも7/29に差し替えた画像（1,975,971B）は差し替え前より小さいため、この変更が原因という線は否定できる
つまり今回の下落は、当サイトが何かを壊したことによるものではない。

「19年もの」は移転の理由にならない

旧ドメインの唯一の優位点は登録年数だが、これは移転を正当化しない。
  • ドメイン年齢そのものは、Googleが有意な評価要因ではないと明言している。 実際に効くのは被リンクと運用実績であり、旧ドメインは長期間403で停止しているため、その資産は既に減衰している。
  • 旧サイトが「【公式】川口メモリアルホール(川口典礼)」で上位に出ていたのは、ドメインが強かったからではない。 タイトルが検索語と完全一致していたから。同じことは現行サイトの /hall/kawaguchi-memorial-hall/ でも実現できる（実際、直前の週まで3.90位を取れていた）。
  • しかもそのページは現在403で死んでいる。「実績のあるドメイン」ではなく「止まって久しいドメイン」というのが実態。

移転してはいけない理由

  • タイミングが最悪。現行サイトは28日比較でクリック +56%・平均順位 2.4改善と伸びている最中。 サイト移転は必ず一時的な順位変動を伴い、伸長を自ら止めることになる。
  • 失うものが大きすぎる。123URLが検索で表示を獲得し、指名検索で1.0位、構造化データ・sitemap・内部リンク・コラム資産がすべて現行ドメインに載っている。 これを別ドメインへ移すのは、1年以上かけて積み上げたものを一度リセットする賭けになる。
  • 周辺すべてが現行ドメイン前提。GSC・GA4・GBP・Google広告・名刺・パンフレット・ポータル掲載（soogi.jp は既に kawaguchitenrei.com を掲載済み）。 移転すればこれら全部の作り直しが発生する。
  • 技術面でも現行が優位。旧はHTTPS非対応・NTT西日本のホスティングで、Next.js / Vercel の現行環境に対して制約が大きい。
  • ブランド表記としても現行が優れる。ハイフンなしのほうが口頭で伝えやすく、誤入力も起きにくい。葬儀は電話で名前を伝える場面が多い業種であり、これは実務上のメリットになる。

301を設定するときの注意

  • まず403を解除できる状態にする必要がある。現状のままでは転送設定そのものが返せない。 NTT西日本のサービス上でリダイレクト設定ができない場合は、ドメインを別のDNS／サーバーへ移管してから転送を設定するのが確実。 ※移管には認証コード（AuthCode）が必要で、NTT西日本経由の場合は移管に制限があることもあるため、契約照会時に併せて確認する。
  • ページ単位のマッピングは不要。旧サイトの個別ページは既に機能していないため、トップ→トップの一括301でよい。
  • 301は最低1年、できれば恒久的に維持する。途中で外すと集約した評価が失われる。
  • 301後もドメインの更新を止めないこと。転送元が失効すれば転送も消え、第三者取得のリスクが戻る。
