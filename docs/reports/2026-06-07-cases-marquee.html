トップ「施行事例」も自動スクロール（marquee）に統一

作成日：2026-06-07 担当：Claude Code

社内記録（Web非公開・noindex）。個人情報・秘密情報なし。

狙い：「お客様の声」と同じ仕様で「施行事例」もトップで自動横スクロール化し、見せられる事例数を増やして回遊・比較検討を後押し。CSSのみ・追加ライブラリなし。

1. 仕様（お客様の声と統一）

項目内容
方式CSSのみの自動横スクロール（marquee）。共用クラス .marquee。
件数公開中の全事例を新しい順に流す（従来はトップ3件のグリッド）。
適用範囲スマホ・PC共通。
挙動左へゆっくり自動スクロール（1周150秒）／ホバーで一時停止／prefers-reduced-motion で停止（全件は「事例一覧を見る」から閲覧可）。
カード幅スマホ280px・PC360px。形式/場所/人数/総額の表示は従来どおり。

2. 共通化（リファクタ）

  • マーキー用CSSを汎用化：.voices-marquee／@keyframes voices-marquee を .marquee／@keyframes marquee にリネームし、「お客様の声」「施行事例」で共用。
  • VoicesSection.tsx のクラス参照も .marquee に更新（挙動・速度は不変）。
  • CasesSection.tsx はカードを CaseCard に切り出し、トラックは同一列2連結＋複製側 aria-hidden/tabIndex=-1 で重複回避。

3. 方針順守

  • トーン（§3）：ゆっくり・控えめ・ホバー停止。配色・レイアウト・CTA不変。
  • アクセシビリティ：一時停止と prefers-reduced-motion 対応。
  • 共通レイアウト（§5）：Header/Footer/MobileBottomCTA 未編集。依存追加なし。
  • 個人情報（§12）：掲載内容は許可済みの既存事例のまま。新規の個人情報なし。

4. 変更ファイル

ファイル内容
components/home/CasesSection.tsx3件グリッド→全件marqueeに変更。CaseCard 切り出し。
app/globals.css.voices-marquee→.marquee に汎用リネーム（速度150s・hover停止・reduced-motion停止）。
components/home/VoicesSection.tsxクラス参照を .marquee に更新（挙動不変）。

5. 確認結果

  • npm run build：✓ 成功・135ページ維持・型エラーなし。
  • 確認URL：/（「施行事例」「お客様の声」がスマホ・PCで自動スクロール）。
