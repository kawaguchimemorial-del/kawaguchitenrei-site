——「川口 葬儀」は上がったのに、なぜか。専門家8名討議と修正判断

結論

1. 「家族葬」が上がらない直接の原因は、2026-07-14 に「家族葬の主ページ（champion）」をトップから /plan/family-funeral/ へ移した判断が、Google に受け入れられなかったことです。

7週間経っても、Google は「川口市 家族葬」の検索に対してトップページを出し続けています（28日窓：トップ 365表示・10.9位、専用ページ 5表示・77.8位）。ところが 7/14 以降トップの title からは「家族葬」を外していたので、トップは「家族葬」の看板を持たないまま家族葬の検索を受けていた。その結果、「葬儀」は title が合っていて 8〜9位、「家族葬」は合っていなくて 10〜17位——という差になっています。

2. Codex が 9/06 にトップの title へ「家族葬」を戻しています。「川口市の葬儀・家族葬｜自社式場・24時間365日対応｜川口典礼」。7/14 の判断を知らずに戻した形ですが、方向としては上記の診断と一致します。ただし専用ページの title も「川口市の家族葬｜…」のままなので、7/14 に解消したはずのカニバリがそのまま復活している状態です。ここは放置できません。

3. 修正は必要。ただし大改修ではありません。「家族葬の主ページはトップ」と正式に決め直し、専用ページを「プランの料金・内容」の役割に分け、トップに家族葬の見出しを1つ立てる。この3点で足ります。仕様書は §6、Opus 向けに docs/seo-research/2026-09-06-family-funeral-champion-spec.md に切り出しました。

2. 専門家8名の討議

A：検索エンジンの仕組み（インデクシング・正規化）

7/14 の判断そのものは、教科書的には正しかった。同じ語で2ページが競合するなら一本化する。ただ一本化する先を間違えた。Google がどちらを選ぶかは、こちらの title ではなく Google 側の評価で決まる。7週間、Google は一貫してトップを選んだ。Google が選んでいるページを champion にするのが一本化の正しいやり方で、選んでいないページに看板を付けても移らない。

Codex の 9/06 の変更は、経緯を知らずにやったものだが、結果として正しい方向に戻している。問題は専用ページ側の title も「川口市の家族葬」のままなので、いま両方が同じ看板を出している。これは直すべき。

B：ローカルSEO

地元3社の型を見てください。花ぜんもあゆみも、トップで「葬儀・家族葬」を並べている。地元葬儀社のトップページは、Google にとって「その会社のローカルエンティティ」そのもので、地域×業種の検索はここに集まる。プランページに地域検索を集めようとするのは、エンティティの中心を外に出そうとする行為で、うまくいきにくい。

もう1点。「川口市 家族葬」は「川口市 葬儀」より商用性が高い語です。ポータル5社が全部いるのはそのため。同じ順位を取るのが「葬儀」より難しいのは構造で、当社の作りが悪いからではない。

C：情報設計・サイト構造

私はもう少し慎重で、専用ページを捨てる必要はないと思います。役割を変えればいい。「川口市の家族葬」という地域の問いはトップが受ける。「家族葬プランの料金・人数・含まれるもの・別途費用」という商品の問いは専用ページが受ける。問いの種類で分けるのが自然で、今のように両方が「川口市の家族葬」を名乗る状態がいちばん悪い。

トップ側には、いま 「家族葬」を含む h2 が1本もない。53回も本文に出るのに見出しにない。champion にするなら、h2 を1本立てて、人数・価格・自社式場・専用ページへの導線をそこに置くべきです。

D：コンテンツ・ご遺族の読み方

ご家族が「川口市 家族葬」と検索するとき、知りたいのは「この地域で家族葬を頼める会社はどこか、いくらか」です。トップに着地して、家族葬の見出しがすぐ見つかり、価格と式場が分かり、詳細へ進める——これで十分です。専用ページへ直接着地させることに、ご家族側のメリットはあまりない。

ただし、トップの h2 に「川口市の家族葬」を立てるとき、他の形式（直葬・一日葬）との並びが崩れないように。家族葬だけを特別扱いして「押し売り」に見える構成は §11 に反します。

E：計測・効果判定

データの読み方で注意が2つ。第一に、7/13 週の 13.9位は表示81回の1週間で、これだけで「title に家族葬があれば13位」とは言えない。ただ方向として、外した直後に 32.3 へ落ちたのは事実で、他に説明がない。

第二に、Codex の変更は 9/06 で、まだデータに一切反映されていない。いま何かを重ねると、9/06 の変更の効果と混ざって判定できなくなる。専用ページの title 修正はカニバリ解消として必要だが、それ以外は 9/06 の効果を2週間見てから。

F：競合・市場

もう一つの見方を出します。「家族葬」は当社が本当に取りたい語なのか。8月の広告レポートで、地名なしの「家族葬 プラン」が 953表示・203クリックで問い合わせ0でした。家族葬で検索する層は比較検討が長く、ポータルで相見積もりを取る。一方「川口市 葬儀」で来る層は、当社の場合、役所・病院の案内から社名を知って調べる導線と重なりやすい。

だから「全部上げたい」は分かるが、優先は「葬儀」の 8〜9位を維持することで、「家族葬」は二番手という配分でよいと思います。専用ページを地域検索の champion にするために大工事をするのは、投資先として割に合わない。

G：運用・ガバナンス

今回いちばん重いのは、順位ではなく7/14 の判断（champion 反転）が「ユーザー確認事項」のまま放置され、9/06 に Codex が別の判断で上書きしていたことです。どちらも記録はある。しかし「いま champion はどちらか」が一箇所に書かれていない。

今回の修正では、CLAUDE.md か docs に「家族葬の主ページ＝トップ」と1行で書くことを必須にしてください。次に Codex か Claude が触るとき、また反転させないために。

H：総合（判断のまとめ役）

整理します。7/14 の判断は「一本化」としては正しいが、一本化する先を Google の選択と逆にした。7週間で移らなかった。Codex が 9/06 に結果的に戻した。いま必要なのは、これを正式な判断として確定し、専用ページの看板を変えてカニバリを消し、トップに見出しを1本立てること。それ以上の工事は、9/06 の効果が出るまでやらない。

「全部上げたい」への答えは、「葬儀」と「家族葬」は同じトップで受ける。だから片方だけ上がる状態は解消に向かう。ただし家族葬は市場が厳しいので、葬儀と同じ順位にはならない。それでも 17位から 12〜13位へ戻れば、1ページ目の下端に届きます。

4. 合意点

  1. 「川口市 家族葬」「川口 家族葬」の主ページはトップと正式に決める。7/14 の反転を取り消し、9/06 の Codex の変更を追認する

  3. トップに「家族葬」を含む h2 を1本立てる。人数・会員価格と通常価格・1日1組の自社式場・専用ページへの導線を置く。他の形式との並びを崩さない
  4. 「家族葬の主ページ＝トップ」を CLAUDE.md に1行で明記する。再反転を防ぐ
  5. 効果判定は 9/20 前後。「川口市 家族葬」が 13位以内に戻れば効果あり

5. やらないこと

  • 専用ページを地域検索の champion にするための増強（7週間で効果なし・Google の選択と逆）
  • エリアページの title 変更（/area/higashikawaguchi/ の 51位は東川口の語として正常。7/05 の判断どおり触らない）
  • 新規ページの作成（8/10 の判断どおり）
