形式別ページの読み物強化＋近隣斎場リンク集（プレイブック⑥）

作成日：2026-06-07 担当：Claude Code

社内記録（Web非公開・noindex）。個人情報・秘密情報なし。出典：改善実装プレイブック の ⑥。

狙い：各形式別プランページに「この形式とは／メリット・デメリット／向いている方」の読み物ブロックを足してページの厚みと滞在価値を上げ、形式比較系クエリ（家族葬とは・一日葬 デメリット 等）とAI回答での引用を狙う。あわせて /saijo/ の寺院会館をエリア別の内部リンクで /area/* に結び、地域ロングテールの回遊を強化する。

1. サマリ

  • 追加 lib/plans.ts に PlanFormatGuide 型（定義／メリット／デメリット・留意点／向いている方）を新設し、家族葬・一日葬・火葬式・直葬の4プランにデータを追加。
  • 追加 components/plan/PlanDetailBody.tsx に PlanFormatGuide 読み物コンポーネントを新設。結論ボックス直後に配置（標準プラン分岐のみ）。
  • 強化 /saijo/（app/saijo/page.tsx）にエリア別ジャンプナビ＋各エリアグループから該当 /area/* への内部リンクを追加。
  • 完了 npm run build 成功・135ページ維持・型エラーなし。

2. 形式別ページの読み物ブロック（①の費用ガイドとは別軸）

標準プラン（家族葬・一日葬・火葬式・直葬）の詳細ページに、結論ボックス直後で以下を表示：

要素内容
この形式とは（定義）形式の定義・特徴を1段落で解説。家族葬⇔一日葬⇔火葬式⇔直葬の違いが伝わる書き方。
メリット各3点。事実ベース・誇張なし。
デメリット・留意点各3点。「煽り」ではなく「事前に整理しておきたい点」として提示（菩提寺への相談・親族間の共有・後日弔問など）。
向いている方各3点。読者の自己判断を助ける。

非表示対象：市民葬・無宗教葬・花入れお別れは formatGuide 未設定のため非表示（専用ボディ／構成を維持）。

3. /saijo/ 内部リンク強化（地域ロングテール）

追加要素内容
エリア別ジャンプナビ寺院会館セクション冒頭に、7エリアグループ見出しへのアンカー（#id）をチップ表示。地域別の探しやすさと内部回遊を改善。
エリアグループ→地域ページ各グループ末尾に該当 /area/* への内部リンク（例：朝日・南鳩ヶ谷方面→南鳩ヶ谷／鳩ヶ谷、本町・舟戸町方面→川口駅周辺、上青木・青木方面→上青木／青木 ほか）。

リンク先は実在する /area/* ページのみ（build の135ページで確認）。施設の利用可否・宗派/檀家条件の新規断定はしていない（既存の「目安・要確認」注記を維持）。

4. 方針順守

項目順守
読ませる構成（§3）カード羅列ではなく定義文＋要点の読み物形式。既存トーン・余白・セリフ体見出しを踏襲。
煽らない（§11）デメリットは「事前に整理しておきたい点」として中立に提示。最安・必ず・絶対などの禁止表現なし。
価格・正本（§9）形式別ブロックに新規金額は記載せず。既存の価格表・構成は変更なし。
施設の断定回避（§19.3）寺院会館・民営式場の利用可否・宗派/檀家条件の新規断定なし。既存の運営主体明記・目安/要確認注記を維持。
