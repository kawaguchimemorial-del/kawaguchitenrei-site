社内記録（Web非公開・noindex）。個人情報・秘密情報なし。出典：改善実装プレイブック の ②。

狙い：「何にいくらかかるか」を表形式で透明化し、費用系クエリ（川口 葬儀 費用 等）の取り込みとAI回答での引用を狙う。①の「川口市 葬儀ガイド」とは重複しないよう、ガイドには概要、/plan/ には詳細内訳表を配置。

1. サマリ

  • 新規 共通コンポーネント components/common/CostBreakdownTable.tsx：項目別内訳の目安表（プラン基本料金・式場使用料・火葬料・搬送・安置・お料理・返礼品・宗教者へのお礼）＋火葬場別の火葬料の目安表（川口市めぐりの森ほか）。各項目に「変動する要素」を明記。
  • 配置 /plan/（app/plan/page.tsx）の CTA 直前に「葬儀費用の内訳の目安」セクションとして設置。
  • 完了 npm run build 成功・135ページ維持・型エラーなし。生成HTMLで反映確認。

2. 内容と方針順守

項目順守
価格（§9正本）プラン基本料金は正本（直葬139,000〜／家族葬528,000〜）。火葬場の火葬料は川口市の公開情報に基づく目安。
目安・断定回避（§14）全行に「変動する要素」、表の下に「目安・正式なお見積りで確認」「改定の場合あり・各施設/川口市で確認」を明記。
禁止表現（§14/§19.3）総額確定・追加費用なし・最安・標準価格は不使用。煽らない（§11）。
火葬場の表記（§19.3）川口市めぐりの森は公開料金の目安を提示。戸田・谷塚等は「施設・利用条件により異なる（要確認）」とし、不確実な金額は断定しない。
