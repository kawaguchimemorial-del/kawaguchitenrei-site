不合格点は 2 つ。A. 承認済みプロジェクトがない（GCP 側の OAuth 同意画面が実サイトと結び付いていない）、B. リスティングが別のウェブサイトに紐づいている。B は 8/7 に発見済みの 3 ドメイン分散問題がそのまま審査に出た形で、GBP API の却下対応と SEO 対策が同じ打ち手に収束することが確定した。

4. ビジネス名称が戻る件 ─ 変更しないのが正解

「株式会社川口典礼 川口メモリアルホール」を「川口典礼」に変更しても元に戻る、という事象。原因は Google が検証済みの名称を保持しているためで、短縮方向の変更は差し戻されやすく、繰り返すと審査対象になる。

確認の結果、登記上の正式名称は「株式会社川口典礼」、建物の看板は「川口メモリアルホール」。現在の登録名は登記名＋看板名であり、Google のガイドライン（実世界で使われている名称）に適合している。加えて「川口メモリアルホール」は順位追跡中のブランドキーワード（3.55→12.88位に下落した語）であり、名称から外す不利のほうが大きい。GBP API の却下理由にも名称は含まれていない。

プレイブックの記載ミスを訂正
2026-07-27-gbp-full-setup-playbook の NAP 正本に「名称：川口典礼」と書いていたのは誤り。実態に合わせて修正し、「名称は変更しない」旨を警告として明記した。
