封筒宛名印刷ツール：CSV読み込み＋一覧ナビゲーション対応

作成：2026-07-22 ／ 対象：/post/（社内用ツール・長形3号）
CSVで宛先一覧を読み込み、印刷ページで「次へ／戻る」で1件ずつ封筒を選んで印刷できるようにした。 ナビゲーションはCSVを読み込んだときだけ表示し、従来の単票入力の動作は変えていない。

1. 追加した機能

場所内容
/post/「CSVを読み込む」ボタン。読み込むと件数・宛名・住所・種別の一覧を表示
/post/「テンプレートCSVをダウンロード」ボタン（UTF-8 BOM付きでExcelがそのまま開ける）
/post/一覧の各行「フォームへ」＝1件をフォームに流し込んで個別修正
/post/print/「◀ 戻る」「次へ ▶」＋「n / N 件目」＋宛先プルダウン。CSV読み込み時のみ表示

2. CSVの形式

1行目を見出しとして列名で対応付ける（列の順番には依存しない）。テンプレートの見出しは次のとおり。

種別,郵便番号,住所1,住所2,住所3,宛名,担当者名

既存の社内CSVもそのまま読める。列名の別名表を持たせ、現場にある2種類の実ファイルで動作を確認した。
  • 請求書一括CSVフォーマット.csv（50列）→ 9件を正しく取り込み。郵便番号・都道府県・市区町村・番地・請求先名を自動対応
  • 20260725 当日参列時支払いリスト.csv（12列）→ 2件を正しく取り込み。住所欄に埋まった「〒110-0004」を郵便番号として切り出し、住所側からは除去

実装中に見つかって直した点：

  • 空の列を掴んでしまう問題：請求書フォーマットは「宛名」列が空で「請求先名」に値が入る。当初は先に一致した列で固定していたため0件になった。→ 該当列を優先順の候補として全部保持し、行ごとに最初の非空セルを採用する方式に変更。
  • 住所欄に郵便番号が同居する一覧：郵便番号列が無い表に対応するため、住所から 〒000-0000 を抽出するようにした。

3. 個人情報の取り扱い（CLAUDE.md §12）

CSVは氏名・住所を含むため、解析はすべてブラウザ内で完結させている。
  • ファイルのサーバー送信は行わない（fetch／アップロードなし）
  • コンソール・サーバーログへの出力なし
  • 一覧の保持は sessionStorage（タブを閉じれば消える）。localStorage には保存しない
  • 「読み込みを取り消す」で明示的に消去可能
  • 本レポートおよびリポジトリに実データ（氏名・住所）は一切含めていない

文字コードは UTF-8（BOM有無）と CP932 を自動判定。Excel（日本語版）の既定保存でも読めるようにした。

4. 種別（個人／会社）の判定

敬称が変わるため重要。優先順位は次のとおり。

  1. 「会社名」列に値 → 会社／「氏名・お名前」列に値 → 個人
  2. 「種別」列の値（個人／会社）
  3. どちらも無い場合は宛名から推定（株式会社・有限会社・センター・商店・工業・組合 等の語を含めば会社）

推定は完全ではないため、画面に「誤っている行は『フォームへ』で修正してから単票で印刷」と明記した。
