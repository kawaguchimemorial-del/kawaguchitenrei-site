お客様の声「気になる言葉」フィルタ（クライアント側・SEO安全）

作成日：2026-06-16対象：/voice/担当：Claude Code

アンケートを1つずつ開かずに、気になる言葉で絞り込めるUX。個人情報・秘密情報なし。

1. 目的・SEO方針

「アンケートに書かれている言葉（親身・直葬・家族葬・費用 等）」で絞り込み→該当アンケート→詳細、という導線を追加。新URLを作らず /voice/ ページ内のクライアント側フィルタで実装したため、URL・title・canonical は不変。初期HTML（SSG）には全30件のアンケートが描画されるため全件インデックス維持＝SEO・6/26測定に影響なし。

2. 実装

  • lib/voices.ts：タグ定義 voiceTags（同義語グループ）＋判定 voiceMatchesTag() を追加。タグは title+comment に含まれる語で自動該当（記事ごとのタグ付け不要）。担当者名など個人名はタグにしない（§12）。マッチ0件のタグは表示しない。
  • components/voice/VoiceFilterList.tsx（新規・"use client"）：件数つきタグchip（すべて＋各タグ）＋絞り込みグリッド。星は StarIcon、矢印は ArrowRightIcon。
  • app/voice/page.tsx：一覧描画を <VoiceFilterList /> に置換（旧 StarRating/formatDate を整理）。ついでに残っていた絵文字 → ☎ も SVG化。JSON-LD（ItemList）は従来どおり全件出力。

採用タグ（マッチがあるもののみ表示）：親身／丁寧／安心／わかりやすい説明／費用・明朗／迅速な対応／家族葬／直葬／一日葬／一般葬／初めて・不安／寄り添い。

3. 確認結果

  • npm run build 成功・TypeScript エラーなし・静的生成 135/135 維持。
  • dev 実測：/voice/ が HTTP 200。初期HTMLに全30件のカード＋タグchip が描画されることを確認（SEO安全）。

影響範囲：/voice/ の絞り込みUX（クライアント側）。構造・価格・式場可否・フォーム・共通chrome に変更なし。

4. 今後のアクション・調整余地

  • 調整可 タグの語・グループは lib/voices.ts の voiceTags 1か所で増減・調整可能。
  • 任意 該当語のハイライト表示、選択タグの件数バッジの見せ方など、好みに応じて調整可能。
