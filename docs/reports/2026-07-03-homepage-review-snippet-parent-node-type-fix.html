トップページ レビュースニペット「項目『<parent_node>』のオブジェクトタイプが無効です」エラー修正

作成日：2026-07-03 対象：https://kawaguchitenrei.com/（トップ） 担当：Claude Code

サマリ

  • Search Console のリッチリザルト（レビュースニペット）で発生していた「項目『<parent_node>』のオブジェクトタイプが無効です」エラーを修正 完了
  • トップページの FuneralHome 構造化データの @type を配列化し、Google がサポートする親型 LocalBusiness を併記 完了
  • commit → push 済み（4a40229・ユーザー承認のうえ §19.2 に沿って実施） 完了
  • 本番反映後のリッチリザルトテスト確認・Search Console「修正を検証」 未・要対応
  • 自社レビューの star 表示適格性（Google ポリシー）の様子見 経過観察

背景・原因

Search Console のリッチリザルト レポートで、https://kawaguchitenrei.com/ に対し 「項目『<parent_node>』のオブジェクトタイプが無効です」（初検出 2026-07-03・該当1件）が報告された。

原因は、トップページの構造化データ（lib/company.ts の getLocalBusinessJsonLd()）で aggregateRating（★4.5・27件）を @type: "FuneralHome" 単独のノードに付与していたこと。 Google のレビュースニペットは aggregateRating の親型として LocalBusiness などの 限定された型のみを認識する。FuneralHome は Schema.org 上は LocalBusiness のサブタイプで技術的には妥当だが、 Google のリッチリザルト判定では単独では有効な親型として認識されず、「<parent_node>（親ノード）のオブジェクトタイプが無効」と判定された。

これは 2026-06-12 に voice 詳細ページで対応した itemReviewed の型エラー（FuneralHome 単独 → 配列化で解消）と同種の問題であり、同じ方針で解消できる。

変更内容

ファイル変更
lib/company.ts getLocalBusinessJsonLd() の @type を "FuneralHome" → ["FuneralHome", "LocalBusiness"] に変更。Google がサポート対象の LocalBusiness として親ノードを認識できるようにしつつ、地域密着の FuneralHome の具体性も保持。
差分（該当箇所） 
  "@context": "https://schema.org",
- "@type": "FuneralHome",
+ // Google のレビュースニペットは LocalBusiness を親型として認識するが、
+ // サブタイプの FuneralHome 単独では aggregateRating の親型として無効判定になる。
+ // 配列で LocalBusiness を併記し、リッチリザルト要件を満たす。
+ "@type": ["FuneralHome", "LocalBusiness"],
  "@id": `${SITE_URL}/#funeralhome`,

aggregateRating の値（★4.5・27件）・住所・電話・営業時間など他のプロパティは一切変更なし。 価格（§9 正本）・式場利用可否・フォーム・Webhook にも影響しない。

確認結果

  • npm run build：成功。TypeScript エラーなし。静的生成ページ数の減少なし（維持）。
  • 変更は lib/company.ts の1ファイルのみ。共通レイアウト（Header/Footer/MobileBottomCTA）・フォーム系は無変更。
  • commit 4a40229・push 済み（ab7491e..4a40229）。aggregateRating を含む JSON-LD 変更のため §19.2 に基づきユーザー承認を得て push。

今後のアクション

  • Vercel デプロイ完了後、Google リッチリザルトテストで https://kawaguchitenrei.com/ を検査し、<parent_node> エラーが消えていることを確認。
  • Search Console のエラー画面で「修正を検証」を実行。
  • 要留意（ポリシー）：Google は「自社が管理するページで自社自身についてのレビュー（aggregateRating）を掲載している場合、star レビュー表示の対象外」としている。 今回の ★4.5・27件は Google マップの実在クチコミだが、自社サイト上に自社の aggregateRating を置く形式のため、検証エラーが解消しても Google が星を表示しない可能性がある（これは検証エラーとは別の「適格性」の問題）。今回の型修正でエラー解消を進めたうえで、星が出るかを経過観察する。
