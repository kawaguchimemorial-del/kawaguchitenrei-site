背景

別セッションの外部診断で、HSTS・TLS・秘密情報の露出は問題なし、一方で XFO / nosniff / Referrer-Policy / Permissions-Policy / CSP が未設定だった。「川口市 葬儀」上位 7 サイトとの比較では HSTS を持つのは当サイトのみで、今回の追加で比較対象中もっとも整った状態になる。
