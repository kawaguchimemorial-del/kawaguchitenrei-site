ホームの絵文字アイコンを実SVGへ統一＋見出しサイズ統一（A＋C＋B）

作成日：2026-06-16対象：トップページ（home セクション群）担当：Claude Code

2026-06-16 のデザイン/UX監査の優先度 P1（A：アイコン統一、C：星のSVG化）の実装。個人情報・秘密情報なし。

1. 背景・狙い

監査で最優先（P1）とした「OS依存の絵文字（☎ ✓ → › ↗ ★）をそのままUIアイコンに使っている」点を解消。絵文字は端末ごとに字形・太さ・色が揺れ、最も「安く・素人っぽく」見える原因のため、統一された線アイコン（B案：stroke 1.75 / round）へ置換した。方向性は事前にサンプル3案（A/B/C）を提示し、ユーザーがB案（標準の中線）を選択。

新規：共通アイコン

B：見出しのスケール統一

セクション見出しのサイズ不揃いを整理。主要セクション見出しを text-3xl md:text-[2.4rem] に統一する方針で、1段下がっていた ThreeStrengthsSection と AdvanceConsultSection の h2 を text-2xl md:text-[2.2rem] → text-3xl md:text-[2.4rem] に引き上げ。MediaLinksSection（掲載メディア）は補足セクションのため、あえて小さいまま据え置き（ユーザー合意済み）。余白・行間などサイズ以外は変更なし。
