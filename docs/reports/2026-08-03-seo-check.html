4. 要観察：/area/kawaguchi/ の後退

/area/kawaguchi/ の平均順位が 20.4位 → 41.1位、表示も -251。 KW別に見ると「川口市 葬儀」で 68.5位→65.7位、「川口市 家族葬」で 76位→79.7位と、 主要語ではもともと圏外であり、7/22 の役割分離（ヘッドKWをトップに集約）の意図どおりの退避。 順位数値の悪化は「上位表示していた指名系クエリ（川口典礼 表示60→13）が抜けて、 低順位クエリだけが残った」ことによる平均値の押し下げで、実害としては小さい。

ただし、意図的な退避であっても「川口市 葬儀 費用」で 27.2位・表示31（前期2）と、 費用軸では /area/kawaguchi/ が拾い始めている。ここは伸ばす余地がある。 7/30 レポートで保留とした「家族葬×川口市の受け皿不在」問題も未解決のままで、 「川口市 家族葬」の受け皿はトップ（13.7位）で、/plan/family-funeral/ は48位と機能していない。

判断：前回同様、今回も動かさない。7/22・7/27 の変更から日が浅く、 短期データで title を往復させるのが最も避けるべき操作。 8/19 の 28日窓測定で「川口市 家族葬」「川口市 葬儀 費用」の受け皿が定まるかを見て判断する。

8. 結論と次アクション

サイト側で今日やるべき緊急対応はなし。今回はコード変更を一切行っていない。
  • 最優先（サイト外）：GBP API 承認確認（8/9頃）。「川口市 葬儀」8.1位でクリック1という構造は、ローカルパック側でしか解けない。

  • 中期の伸びしろ：/column/kenshi-nagare/・/column/fuhou/ の本文強化で 9〜10位 → 5位圏内を狙う。ただし全国区の情報KWであり受注直結ではないため、川口軸の施策より優先度は下。
  • 観察継続：「川口市 一日葬」16.2位→21.2位の後退、/area/kawaguchi/ の費用軸での表示増（27.2位・表示31）。
