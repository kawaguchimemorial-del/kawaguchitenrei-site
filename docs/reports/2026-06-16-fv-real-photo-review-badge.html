FVを合成画像から「実物の最適化写真」へ＋口コミ総合評価バッジ

作成日：2026-06-16対象：トップ FV / 口コミバッジ担当：Claude Code

競合FV/UX分析で最大ギャップだった「合成ヒーロー」と「社会的証明の不在」を同時に解消。個人情報・秘密情報なし。

1. FV：合成 → 実物の最適化写真（PC・モバイル共通）

  • 従来の合成FV（外観＋宙に浮く祭壇 hall-fv-pc.png / hall-fv-mobile.png）は合成感が出て競合水準を下回るため不使用に。
  • 手持ちの実写 建物.png（川口メモリアルホール外観）を sharp で最適化（AI生成ではなく実物の補正）：右端の雑多をトリミング／明るさ+3%・彩度+7%・軽いコントラスト／mozjpeg q84 で 2.5MB PNG → 285KB JPEG（1578×880）。看板「川口メモリアルホール」がくっきり。
  • 出力を public/images/home/hero/hall-exterior-hero.jpg に配置し、PC・モバイル同一画像に。
  • モバイルFVの比率を aspect-[9/16]（縦長）→ aspect-[4/3]（横向き寄り）に変更し、横位置の建物写真が1枚で両対応できるように。alt も実態に統一。

方針メモ：葬儀社の建物はAIで作り変えない（実在の式場であることに価値・§13）。今回は“実物の補正”に限定。電線除去等の本格レタッチは未実施（必要なら別途）。

2. 口コミ総合評価バッジ（FV直下「安心の根拠」帯）
