高intentコラムの「文脈に沿ったCTA」対応（funnel強化）

作成日：2026-06-16対象：コラム CTA担当：Claude Code

競合分析の指摘（記事→相談の funnel）を受けた改善。個人情報・秘密情報なし。

1. 前提：funnel は既に強い

調査の結果、コラムの導線はすでに充実していた：

  • テンプレ側：記事末CTA（事前相談＋見積り）／PCサイドバー固定の電話・事前相談／関連記事／最下部の深緑CTA（#consultation）。
  • 記事側：本文中CTA（ctaブロック）が44記事に計58個。ラベルも「家族葬プランの詳細を見る」「概算見積りを依頼する」等、ある程度文脈化済み。

＝量は不足していない。唯一の汎用部分は、本文中CTAの“説明文”が全記事固定（「詳しい内容や費用感は…ご相談ください」）だった点。

2. 変更内容（文脈テキスト対応）

  • lib/columns.ts：ctaブロックに任意の text?: string を追加（型拡張）。
  • components/column/ColumnBody.tsx：cta の説明文を block.text ?? 既定文 に。未指定の記事は従来どおり。
  • 高intent 3記事の主要CTAに文脈文を追加：
    記事追加した文脈文
    補助金（hojokin）葬祭費・埋葬料などの申請の確認や、川口市での葬儀費用のご相談は、川口典礼までお気軽にどうぞ。
    葬祭扶助（sousai-fujo）葬祭扶助を利用したお葬式（火葬中心）のご相談・手配は、川口典礼が制度に沿ってお手伝いします。
    互助会解約（gojokai-kaiyaku）互助会の解約や積立金を活かした葬儀のご相談、見積りの比較も、川口典礼で承ります。

断定・煽り（最安/必ず 等）なし・§11／競合名なし・§15／価格は §9 正本のみ（具体金額は本文の既存記述に準拠、今回は追加せず）。

3. 確認結果

  • npm run build 成功・TypeScript エラーなし・静的生成 135/135 維持。

影響範囲：コラム本文中CTAの説明文（高intent 3記事）。構造・価格・式場可否・フォーム・共通chrome に変更なし＝SEO 影響なし（むしろ高intent記事の相談導線が文脈化）。

4. 今後のアクション

  • 任意 他の高intent記事（費用 hiyou/sousaihi、家族葬 kazokusou 系）にも文脈文を展開可能。
  • 対応済み コラム詳細ページ（app/column/[slug]/page.tsx）の絵文字 ☎ → ← をSVG化（PhoneIcon/ArrowRightIcon/ArrowLeftIcon。ArrowLeftIcon を共通アイコンに追加）。アイコン統一の取りこぼしを解消。
  • 後回し FV写真の本格レタッチ（Canva）は費用対効果低めのため保留。
