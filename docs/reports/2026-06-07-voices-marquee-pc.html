PCトップ「お客様の声」を自動スクロール（marquee）に変更

作成日：2026-06-07 担当：Claude Code

社内記録（Web非公開・noindex）。個人情報・秘密情報なし。

狙い：30件あるお客様の声を、PCトップで自動的に横へ流して回遊・信頼補強。CSSのみ（追加ライブラリなし）でトーンを崩さない控えめな実装。実装前にユーザーへ方式・件数・範囲を確認し合意のうえ実施。

1. 仕様（合意内容）

項目内容
方式CSSのみの自動横スクロール（marquee）。package.json 変更なし。
件数公開中の全件（30件）を新しい順に流す。
適用範囲PCのみ（hidden md:block）。モバイルは現状維持（最新2件の縦並び）。
挙動左へゆっくり自動スクロール（1周80秒）／カードにホバーで一時停止／prefers-reduced-motion で自動停止（全件は「すべて見る」から閲覧可）。
カード幅360px・コメントは5行クランプで高さを揃える。リンク・★評価は従来どおり。

2. 実装メモ

  • トラックは同一カード列を2連結し、translateX(0 → -50%) の無限ループでシームレス化。複製側の <li> は aria-hidden、リンクは tabIndex=-1 で読み上げ・キーボードの重複を回避。
  • カード描画は VoiceCard に共通化（モバイル縦並びとPCマーキーで共用）。
  • キーフレーム voices-marquee は既存の app/globals.css のアニメーション規約（@keyframes＋prefers-reduced-motion ブロック）に合わせて追加。

3. 方針順守

  • トーン（§3）：ゆっくり・控えめ・ホバー停止で落ち着いた印象を維持。配色・レイアウト・CTAは不変。
  • アクセシビリティ：自動移動コンテンツに必須の「一時停止」と prefers-reduced-motion 対応を実装。
  • 共通レイアウト（§5）：Header/Footer/MobileBottomCTA 未編集。依存追加なし（§5/§19.2 非該当）。
  • 個人情報（§12）：表示内容は既存のお客様の声（許可・マスキング済み）のまま。新規の個人情報なし。

4. 変更ファイル

ファイル内容
components/home/VoicesSection.tsxPC＝全件marquee、モバイル＝現状維持。VoiceCard 共通化。
app/globals.css.voices-marquee ＋ @keyframes voices-marquee（hover停止・reduced-motion停止）を追加。
