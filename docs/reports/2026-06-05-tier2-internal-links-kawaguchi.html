Tier2 内部リンク強化：/area/kawaguchi/ から各専用プランへの地名アンカー集約

作成日：2026-06-05 施策バッチ：Tier2（地域×形式）第1作業 担当：Claude Code

本レポートは docs/reports/ 配下の社内記録（Web非公開・noindex）。個人情報・秘密情報なし。前提分析は 同日のSEO分析レポート を参照。

1. サマリ

  • 完了 app/area/kawaguchi/page.tsx の関連リンク欄に、専用プランページ5件を地名×形式アンカーで追加。
  • 完了 npm run build 成功・静的生成133ページ（減少なし）。
  • 予定 続く第2作業（専用プラン→エリアページの逆リンク／他エリアページ横展開）は別途承認のうえ実施。

2. 背景・狙い

3か月の GSC 分析で、川口 家族葬（9.9〜11位）・川口 直葬・川口 一日葬 等の地域×形式クエリが、本来の専用プランページではなくトップ / 経由で表示していることが判明。原因はコンテンツ不足ではなく「ページの新しさ＋専用ページへの内部リンク評価の不足」。

対策の本筋は「地名×形式アンカーで専用プランページへの内部リンクを増やし、トピック信号を集約する」。その第1歩として、川口の地域ハブである /area/kawaguchi/ から各専用プランへのリンクを地名アンカーで拡充した。

3. 変更内容

対象：app/area/kawaguchi/page.tsx の relatedLinks 配列（1ファイルのみ）。

従来はプラン系リンクが「家族葬プラン」1件のみ。これを地名アンカー付き5件に拡充：

アンカー（label）リンク先説明の価格（§9正本）
川口市の家族葬/plan/family-funeral/528,000円(税込)〜
川口の一日葬/plan/oneday-funeral/396,000円(税込)〜
川口の直葬/plan/direct-funeral/139,000円(税込)〜
川口の火葬式/plan/cremation/価格表記なし（相談表記）
川口市民葬/plan/kawaguchi-shimin/231,000円(税込・川口市民)

本文 AreaPlans は元々これらプランへリンク済みだが、アンカーが「家族葬の詳細を見る」等で地名を含まなかった。関連リンク欄に地名×形式アンカーを補うことで、専用ページに対する topical signal を補強する狙い。

4. 確認結果

  • npm run build：成功（エラー・警告なし）。
  • 静的生成：133ページ（編集はルート数を変えないため減少なし）。
  • 価格は §9 プラン正本のみ使用。火葬式は正本に金額がないため価格を出さず相談表記。
  • デザイン・トーン・式場利用可否・フォーム・共通レイアウトは未変更。

5. 今後のアクション

  1. 第2作業（要承認）：各専用プランページ relatedLinks から /area/kawaguchi/ への逆リンクを地名アンカーで確認・補強。
  2. 第3作業（要承認）：他エリアページ・関連コラムからの横展開。トップページの導線は design 配慮のうえ別途検討。
  3. 再測定：2026-06-26 頃に GSC を再取得し、対象クエリの着地ページが / から専用ページへ移ったか・順位が上がったかを確認。
