Vercel Web Analytics 導入（ページビュー計測）

作成日：2026-06-08 担当：Claude Code commit/push は確認後

社内記録（Web非公開・noindex）。個人情報・秘密情報なし。

目的：Vercel 上で稼働中の kawaguchitenrei-site に Vercel Web Analytics を導入し、ページビュー計測を開始する。CTAクリック等のカスタムイベントは今回は実装しない。SEO改善タスクとは分離。

1. 変更内容

  • @vercel/analytics を依存追加（npm i @vercel/analytics。1パッケージ追加）。
  • App Router の root layout（app/layout.tsx）に <Analytics /> を追加。import { Analytics } from "@vercel/analytics/next";、<body> 末尾付近（RevealOnScrollSlot の後）に設置。
  • 既存の metadata・GoogleTagManager・レイアウト・デザイン・CTA・構造化データには変更なし。

2. 変更ファイル

ファイル内容
package.json@vercel/analytics を dependencies に追加。
package-lock.jsonロックファイル更新（依存追加分）。
app/layout.tsximport 追加＋<body> 末尾に <Analytics /> を追加。

3. build 結果

  • npm run build：成功（✓ Compiled successfully・型エラーなし）。
  • 静的生成ページ数：135ページ維持（導入前後で増減なし）。

4. 計測開始のしくみ（Vercel 側）

  • 本コードを Vercel にデプロイ後、公開サイトを訪問するとページビュー計測が始まる。
  • Vercel ダッシュボードの対象プロジェクト → Analytics タブで、Web Analytics を有効化（未有効の場合）し、計測データを確認する。
  • 反映には実トラフィックが必要。デプロイ直後はデータ0で、訪問が発生してから数値が表示される。
  • 今回はページビューのみ。カスタムイベント（CTAクリック等）は未実装。

5. 方針順守

  • 新規デザイン変更なし。CTA・構造化データ・metadata 不変。
  • カスタムイベント未実装（今回スコープ外）。
  • SEO改善タスクとは混在させていない（本変更のみ）。
  • package.json / lockfile 変更を含むため、commit / push は人間確認後（§19.2）。本レポート時点では未commit・未push。

6. 備考
