# 03. 改修ロードマップ（P0 / P1 / P2）

このファイルは、kawaguchitenrei.com の改修タスクを優先度別に整理したロードマップ。
各項目に「目的 / 対象ページ / 期待効果 / 注意点 / 実装前チェック / 完了条件」を持たせる。

判断軸は `CLAUDE.md` §10 の「検索される・AI に引用される・問い合わせにつながる」。
評価は `docs/eval/seo-aio-checklist.md`。

凡例：
- **P0**：基盤・即効性が高くリスクの低い改修
- **P1**：コンテンツ拡張・導線強化
- **P2**：運用最適化・周辺強化

---
