## お願いしたいこと

### ステップ1：現状確認（変更しない・まず見るだけ）

GBP 管理画面をブラウザで開き、以下を確認して**事実だけ**を記録してください。プレイブックは作ってあるのですが、**実際に管理画面へ設定したかどうかの記録が残っていません**。

- メインカテゴリと追加カテゴリの実際の設定値
- 営業時間（24時間営業になっているか。特別営業時間の有無）
- 属性のうちONになっているもの
- ビジネス説明文の有無と文字数
- Q&A の投稿数
- 写真の枚数と、直近の追加日
- 投稿の直近の日付と頻度
- 口コミの件数・平均評価・**未返信のものが何件あるか**
- ウェブサイト欄・予約リンク・見積もりリンクのURL

### ステップ2：差分の洗い出しと提案

ステップ1の実測と、チェックリスト／プレイブックの「あるべき状態」を突き合わせ、**差分の一覧**を作ってください。各項目について、

- 現状 → あるべき状態 → 変更案（説明文などは実際の文面まで）
- その変更が公開情報に影響するか
- 根拠（プレイブックの該当節）

### ステップ3：松澤の承認を得てから反映

**公開情報の書き換えは、差分一覧を松澤に提示して承認を得てから行ってください。** 勝手に反映しないこと。承認後に反映したら、公開側の表示まで確認します（2026-09-06 の一日葬価格の訂正と同じ流れです）。

### ステップ4：記録

- 実測と差分と反映結果を `docs/operations/gbp/` に日付つきで残す
- `docs/reports/` に日本語HTMLのレポートと `index.html` へのリンクを追加（`skills/work-report/SKILL.md` に従う）
- commit / push は松澤の明示指示があるときだけ

## 守っていただきたいこと

**絶対にやらないこと**

- **カテゴリに「火葬場」を選ばない。** 川口市めぐりの森は川口市営で当社の運営施設ではありません。自社運営のように見せる表現は CLAUDE.md §19.3 の停止条件に該当します
- **名称欄にキーワードを入れない**（「川口典礼｜川口市の家族葬」のような表記）。ガイドライン違反です
- **口コミの見返り提供・自作自演・購入・低評価だけを書かせない誘導**をしない。またそれを提案しない
- **事実でない属性**（女性経営・LGBTQ+フレンドリー等）を設定しない
- サービス提供地域を広げすぎない（近接性の判定が薄まる場合があります）

**価格について**

- 正本は `CLAUDE.md` §9、実装データは `lib/plans.ts`。**GBP に載せる金額はこのどちらかと必ず一致させてください**
- サイトは事前相談会員価格を主表示、GBP は通常価格を主表示という違いがあります。**この違い自体は誤りではありません**。会員価格・通常価格・市民葬価格・別途費用を混同しないでください
- 2026-09-06 に一日葬が469,000円で登録されていた不一致を496,000円へ訂正済みです。他に同種のずれがないか確認してください

**写真について**

- **遺影・名札・会葬礼状・故人様・喪主様が写るものは掲載不可。** 掲載前に必ず人間が目視確認します（CLAUDE.md §13・§12）
- 既存画像のファイル名・配置場所は変更しない

**口コミ返信について**

- 個人名・故人名・喪主名・葬儀の日程や内容の詳細を書かない
- 低評価への返信で事実関係を公開の場で争わない。反論・言い訳・ご遺族の状況説明はせず、**電話への誘導までで止める**（文面はプレイブック §8-3）

**API について**

- GBP API は 2026-08-21 に再申請（ケース 8-8661000041490）し、**2026-09-06 時点で未承認**です（メール0通、`scripts/gbp/dump.mjs` は 429＝割り当て0）
- `scripts/gbp/apply.mjs --confirm` は公開情報を書き換える操作です。**今回のような確認・整備のタスクでは実行しないでください**
- **API の承認を待つ必要はありません。** 上記の作業はすべてブラウザの管理画面でできます

**そのほか**

- 順位・表示回数・問い合わせ件数の改善を保証する書き方をしない。実測値には確認日を付ける
- GBP の「通話」は通話ボタンのクリック数で、実際の着信ではありません。GA4 の `click_tel` とも別の場所での操作なので、**人数として合算しない**（`docs/operations/2026-09-04-call-tracking.md`）
- `.env*` と秘密情報の値は読まない・表示しない・記録しない

## 優先順位

チェックリストの §3 のとおりです。**優先1は口コミの運用**（現状28件・★4.5。競合は3,000件超なので件数では追わず、鮮度と全件返信で差をつける）。次いで写真、週1投稿、NAP統一とポータルの誤価格訂正の順です。
