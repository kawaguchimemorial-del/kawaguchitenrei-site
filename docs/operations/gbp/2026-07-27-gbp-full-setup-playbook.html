0. なぜGBPを徹底するのか

葬儀の地域検索は、クリックの大半をローカルパック（地図3枠）が取ります。サイト改善だけでは、この枠には入れません。

Googleがローカルパックを決める3要素は「近接性・関連性・知名度」。このうち：

要素現状動かせるか
近接性鳩ヶ谷 2.45km ／ 東川口 2.66km ／ 川口駅 5.86km（実測）動かせない（座標で固定）
関連性カテゴリ・説明文・サービス登録・属性で決まる動かせる ← 本書の主戦場
知名度口コミ件数・鮮度・サイテーション・被リンク動かせる（時間がかかる）
方針
川口駅前の枠を正面から狙うのではなく、鳩ヶ谷・新井宿・東川口・めぐりの森周辺で確実に枠を取り、関連性を100%まで詰め切る。

⛔ GBP の名称は変更しない（2026-08-19 追記）
「川口典礼」に短縮しようとしても、Google 側が「株式会社川口典礼 川口メモリアルホール」に自動で戻す事象を確認済み。 短縮方向の変更は差し戻されやすく、繰り返すと審査対象になります。

現在の登録名は登記名（株式会社川口典礼）＋看板名（川口メモリアルホール）で、 Google のガイドライン（実世界で使われている名称）に適合しているためそのままが正解です。 「川口メモリアルホール」は順位追跡中のブランドキーワードでもあり、名称から外す不利のほうが大きい。

なお GBP API の却下理由に名称は含まれていません（指摘はウェブサイト欄のみ）。
