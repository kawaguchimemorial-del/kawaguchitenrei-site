## 0. なぜ GBP が最優先なのか（1分で思い出す用）

葬儀の地域検索は、クリックの大半を**ローカルパック（地図の3枠）**が取る。サイトをどれだけ磨いてもこの枠には入れない。

Google がローカルパックを決めるのは「近接性・関連性・知名度」の3つ。

| 要素 | 当社の状況 | 動かせるか |
|---|---|---|
| 近接性 | 鳩ヶ谷2.45km／東川口2.66km／川口駅5.86km | **動かせない**（座標で固定） |
| 関連性 | カテゴリ・説明文・サービス登録・属性 | **動かせる ← ここが主戦場** |
| 知名度 | 口コミの件数と鮮度・サイテーション・被リンク | **動かせる（時間がかかる）** |

2026-08-07 の花ぜん比較の結論：**サイトの品質ではすでに勝っている**（当社129URL vs 花ぜん静的20ページ）。それでも負けるのは、立地とローカルパックというサイトの外側の要因。**立地は変えられないが、GBP は変えられる。**

方針：川口駅前の枠を正面から狙わず、**鳩ヶ谷・新井宿・東川口・めぐりの森周辺**で確実に枠を取る。

## 3. 残っている作業（優先順）

### 優先1：口コミを毎月コンスタントに積む ← 知名度の本丸

- 現状28件。競合は3,000件超なので**件数で正面から追わない**。**鮮度（毎月数件）と返信の質**で差をつける
- 依頼のタイミングは**ご葬儀直後ではなく四十九日前後**。お礼状やご案内に短縮URL＋QRを1つ添える程度で、口頭で強く求めない
- **全件に48時間以内で返信**（文面はプレイブック §8-3。★5／★3／★1 の3パターン用意済み）
- 返信に**個人名・故人名・喪主名・葬儀の日程や内容**を書かない
- 低評価への返信で**事実関係を公開の場で争わない**。電話への誘導までで止める

### 優先2：写真の追加（月2〜4枚を継続）

- 外観・館内・式場・個室面会室・ご親族控室・駐車場・めぐりの森近接
- **遺影・名札・故人・喪主が写るものは不可。掲載前に必ず人間が目視確認**
- 一度に大量投入して放置するより、更新の鮮度が評価される。スマホ撮影で構わない

### 優先3：週1の投稿

- 火曜など曜日を決めて10分。12週分のテンプレはプレイブック §7
- **週1という頻度は社内目標で、Google が示す順位向上の必須条件ではない**（2026-09-06 Codex 指摘）。写真の月2〜4枚も同じ
- 煽らない文体。禁止表現（最安・必ず・絶対・追加費用なし 等）を入れない

### 優先4：サイテーション（NAP を全媒体で一致させる）

**NAP 正本（各媒体の表記をこれに合わせる）**

> 表記の統一は望ましいが、**「1文字違えば知名度が分散する」という断定の根拠はない**（2026-09-06 Codex 指摘）。
> 実世界で認識されている表記を基準にし、統一のためだけに GBP の名称を変更しない。

```
名称: 川口典礼（川口メモリアルホール）
住所: 〒333-0833 埼玉県川口市西新井宿440-1
電話: 0120-963-765
受付: 24時間365日
```

- [ ] Yahoo!ロコ / Bingプレイス / Appleマップ を正本に統一
- [ ] 主要ポータル（いい葬儀・小さなお葬式・よりそう・soogi・エキテン等）の掲載を正本に統一
- [ ] **外部ポータルの価格表記を正本と照合し、条件が欠けているものは訂正依頼**
  - 「つながり」の旧プラン名・正本と異なる価格・追加費用の広い断定表現
  - **8.8万円という数字だけを見て「誤価格」と決めない。** シンプル直葬プランの事前相談会員価格88,000円（通常138,000円・〜5名・宗教的物品なし・お預かり中の面会なし）として実在する。確認するのは金額そのものではなく、**プラン名・会員条件・人数・面会条件・別途費用が正しく併記されているか**（2026-09-06 Codex 指摘。同じ誤認を4回繰り返している）
  - 訂正できない媒体は記録に残す
- [ ] 実在確認できた自社プロフィールURLを控える → `lib/company.ts` の `sameAs` に追加（**推測URLは不可**）

## 4. 絶対にやらないこと（アカウント停止リスク）

- 名称欄へのキーワード詰め込み（「川口典礼｜川口市の家族葬」等）
- カテゴリに「火葬場」を選ぶ
- 口コミの見返り提供・自作自演・購入・低評価だけを書かせない誘導
- 事実でない属性（女性経営・LGBTQ+フレンドリー等）の設定
- サービス提供地域を実態より広く設定する（※「広いと近接性が薄まる」という因果は公式には確認できていない。実際の対応範囲に合わせる、という理由で判断する）

## 5. 計測（毎月1日・20分）

- GBP インサイト：表示・通話ボタン・ルート検索・サイトクリック
- ローカルパックに入っているかを目視（**シークレットウィンドウ＋位置情報オフ**、または位置を鳩ヶ谷駅付近に指定。自分のスマホは現在地と履歴で結果が歪む）
- 口コミの件数と鮮度、参照ドメイン数

**8月の実績**：操作合計は7月比20.0%減、通話ボタン13→4、サイトクリック40→35。母数が小さく季節変動もあるため、これだけで原因を断定しない。

**注意**：GBP の「通話」は通話ボタンのクリック数で、実際の着信ではない。GA4 の `click_tel` とも別の場所での操作なので**人数として合算しない**（[電話着信記録の運用](../2026-09-04-call-tracking.md)と突き合わせる）。
