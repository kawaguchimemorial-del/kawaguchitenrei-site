## 取得できたこと

### 近接性（proximity）の定量化 ★これは確定値

Nominatim（OSM）で座標を取得し、直線距離を算出。基準＝西新井宿440-1（〒333-0833 / 35.85287, 139.73394）。

| 検索地点 | 直線距離 |
|---|--:|
| 鳩ヶ谷駅 | **2.45 km** |
| 東川口駅 | **2.66 km** |
| 西川口駅 | 4.92 km |
| 川口駅 | 5.86 km |
| 川口駅×西川口駅 中点 | 5.32 km |

**解釈**：Google ローカルパックの3要素（近接性・関連性・知名度）のうち、近接性は座標で決まる固定値で、施策で動かせない。人口・検索が集中する川口駅／西川口駅から約5〜6km は、都市部の葬儀カテゴリでは**ローカルパック圏外になりやすい距離**。

一方、鳩ヶ谷・東川口は 2.5km 圏内で**近接性で戦える**。これは GSC の実データ（鳩ヶ谷 表示54→174、青木 31→96、芝 13→54 と周辺エリアページが伸長／`/area/kawaguchi/` のみ 425→201 と後退）と方向が一致する。

→ **「川口市全域の地図枠」ではなく「鳩ヶ谷・新井宿・東川口・めぐりの森周辺の地図枠」を目標にすべき**という前回の判断を、数値が裏づけた。

### OSM 掲載状況

- `川口典礼` … OSM に登録あり（岩槻街道／桜町二丁目、〒333-0833）

## 判断待ち

ジオグリッド計測を実施するなら **DataForSEO の API キーが必要**（`.env.local` に `DATAFORSEO_LOGIN` / `DATAFORSEO_PASSWORD`）。7x7グリッド×1KWで概ね数十円〜数百円規模。

計測しない場合でも、上記の近接性データだけで「鳩ヶ谷・東川口・新井宿に寄せる」という方針判断は下せる。**計測はあくまで効果検証用であり、着手の前提条件ではない。**
