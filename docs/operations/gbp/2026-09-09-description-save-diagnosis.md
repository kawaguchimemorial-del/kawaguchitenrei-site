### 見立て

**493文字の末尾にある「電話：0120-963-765 ／ 048-281-1117」が、Google に弾かれていると考えられる。**

Google のガイドラインでは、ビジネスの説明について次のように定められている。

- 説明文に **URL や HTML を含めない**（[説明の追加・編集](https://support.google.com/business/answer/3039617?hl=en)）
- **リダイレクトする電話番号や URL を記載しない**（[ビジネス情報のガイドライン](https://support.google.com/business/answer/3038177?hl=en)）
- 説明文はプロモーション・価格・セール情報ではなく、事業の内容そのものに集中させる

「概要欄には493文字が出るのに、編集欄と公開は271文字」という状態は、**過去に493文字が投稿され、Google 側で却下されて旧文に戻された**と考えると自然に説明がつく。保存ボタンが押せて、審査中の表示も出ず、開き直すと元に戻る、という挙動は「受け付けたが採用しなかった」形と一致する。

> **この文面を書いたのは Claude Code（2026-07-27 のプレイブック §3）である。** 同じ §3 の中に「⚠️ 説明文の冒頭で電話番号や URL を羅列しない」と自分で注意書きを置きながら、本文の末尾に電話番号を入れていた。矛盾したものを渡していた。

### 対処案（まず試すこと）

**電話行を削った461文字で保存する。** 他は1文字も変えない。

- 493文字 → **461文字**（削るのは末尾の1段落32文字のみ）
- 電話番号は、GBP では説明文ではなく**電話欄**に登録されている（主 0120-963-765・副 048-281-1117 を 9/06 に確認済み）。説明文から消えても連絡先の情報は失われない
- これで保存が持続すれば原因確定。**まだ戻るなら別の原因**（自動入力とエディタの相性など）なので、そのときは手動での入力を試す

## 2. P4 の「このボタンにはリンクが必要です」

**投稿本文に電話番号が入っていないことは確認済み**なので、Google の投稿ポリシー（[投稿に電話番号を含めることは認められない](https://support.google.com/business/answer/7213077?hl=en)）には触れていない。

残る可能性は、**URL 欄への入力が Google 側の入力状態として登録されていない**こと。自動入力で値を直接書き込むと、画面には文字が出ていても、内部的には未入力のまま扱われることがある。Codex も「本文175文字とURLは画面と入力値の両方で一致した」が送信できなかったと記録している。

- **対処：手動でURL欄をクリックして入力し、いったん別の場所をクリックしてから送信する**（Codex の次の手順と同じ）
- URL の前後に空白が入っていないかも確認する
- **回避策として URL を外したりボタンを電話に変えたりしない**。承認済みの内容から勝手にずらさない
