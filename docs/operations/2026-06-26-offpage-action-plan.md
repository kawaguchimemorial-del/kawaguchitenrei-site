LLMO観測で「火葬式 8.8万円」など**正本と食い違う安値**が外部ポータルに掲載されている問題。期待値ズレ＝トラブルの種。

### 対象ポータル（掲載確認・修正依頼先）
| ポータル | 確認すること |
|---|---|
| 安心葬儀(ansinsougi.jp) | 「火葬式8.8万円」など正本にない価格 → 修正/削除依頼 |
| 葬儀の口コミ(soogi.jp) | 価格・NAP・プラン名の整合 |
| いい葬儀(e-sogi.com) | 「葬儀費用13万円〜」等の表記・NAP |
| 葬儀屋さん(sougiyasan.jp) | プラン価格の整合 |
| その他（みんなが選んだお葬式 等） | NAP・価格・営業情報 |

- [ ] 各ポータルの自社掲載ページを開き、価格・社名・住所・電話を**正本と照合**
