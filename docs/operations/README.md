# 運用作業ログ (operations)

このフォルダは、**人が手動で行う運用作業**の履歴を残す場所です。

## 対象とする作業

- Search Console（sitemap 送信、URL 検査、インデックス登録リクエスト、カバレッジ確認 など）
- 本番環境での目視確認・スマホ実機確認
- 構造化データテスト（Rich Results Test, Schema Markup Validator）
- 広告管理画面の操作（Google 広告、Yahoo! 広告 など）
- 外部ツール上の運用作業全般

ブラウザ上での手動操作が中心で、コードや設定の変更を伴わないものはここに記録します。

## docs/eval/records/ との使い分け

| フォルダ | 目的 |
|---|---|
| `docs/eval/records/` | **実装完了レポート**（コード変更を含む施策の完了記録） |
| `docs/operations/` | **手動運用ログ**（Search Console など、リポジトリ外のツール操作の履歴） |

施策のコード実装は `docs/eval/records/` に、その施策に紐づく Search Console 等での手動作業は `docs/operations/` に記録します。両者は相互にリンクで参照する想定です。

## ファイル命名ルール

```
YYYY-MM-DD-作業内容.md
```

例:
- `2026-05-24-p1-batch1-area-pages.md`
- `2026-06-01-sitemap-resubmit.md`

日付は作業実施日（または記録作成日）。複数日にわたる作業の場合は開始日を採用します。

## 記録ファイルに含める内容

1. **概要**
   - 対象施策、関連コミット、関連 docs、作業目的
2. **対象 URL / サイトマップ**
   - 作業対象を明示
3. **実施前チェックリスト**
   - 何をやるか、未実施／成功／エラーで状況を残す
4. **結果・メモ**
   - エラー内容、画面で観察した内容
5. **次回確認予定**
   - 数日後のインデックス確認など、フォローアップ事項
6. **注意事項**
   - 短期間の連続リクエスト禁止、本番反映確認後に送信、など

テンプレートが必要な場合は、`search-console/` などサブフォルダの既存ファイルを参考にしてください。

## 運用上の注意

- Search Console や広告管理画面の **スクリーンショットは個人情報・問い合わせ内容が写り込まないよう注意**してください。
- API キー、Webhook URL、その他の秘密情報を記録ファイル内に書かないでください。
- 同じ URL へのインデックス登録リクエストを短期間に繰り返さないでください（Google のガイドラインに反します）。
