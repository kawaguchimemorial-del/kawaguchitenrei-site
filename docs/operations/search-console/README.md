# Search Console 作業ログ

このフォルダは、**Google Search Console 上で行った手動運用作業**の履歴を保存します。

## 記録対象の作業

- `sitemap.xml` の送信・再送信
- URL 検査（個別 URL の状態確認）
- 公開 URL テスト
- インデックス登録リクエスト
- カバレッジ（ページのインデックス登録）確認
- 検索パフォーマンスのスナップショット記録
- 手動による対策（manual action）通知への対応

## ファイル命名ルール

```
YYYY-MM-DD-作業内容.md
```

例:
- `2026-05-24-p1-batch1-area-pages.md` — P1 Batch 1 エリアページ追加に伴う送信作業
- `2026-06-15-coverage-check.md` — カバレッジ定期確認

## 記録ファイルに含める内容

1. **概要**
   - 対象施策、関連コミット、関連 docs、作業目的
2. **対象サイトマップ / 対象 URL**
3. **作業チェックリスト**
   - URL ごとに「URL 検査」「公開 URL テスト」「インデックス登録リクエスト」をチェック
   - 結果（未実施 / 送信済み / エラー）と、必要に応じてメモを残す
4. **作業後の確認予定**
   - 数日後のインデックス状況再確認
   - エラーが出た場合の原因調査と対応
5. **注意事項**
   - noindex / canonical / redirect の異常がないか
   - 本番反映後に送信する
   - 短期間の連続リクエストを避ける

## 注意事項

- Search Console の操作はすべて **ブラウザ上での手動作業**です。リポジトリ内には記録テンプレートとログを残すのみで、自動化は行いません。
- 同一 URL に対するインデックス登録リクエストを **短期間に何度も繰り返さない** でください。
- `sitemap.xml` は **本番反映が完了してから** 送信してください。プレビュー URL や反映前の URL を送信しないこと。
- URL 検査で `noindex` / 意図しない `canonical` / 想定外のリダイレクトが検出された場合は、**先にサイト側を修正** してから再送信します。
- スクリーンショットを記録に貼る場合、検索クエリやユーザー情報に個人情報が写り込まないよう確認してください。
