# 05. コンテンツガイドライン（文言・トーン・表現ルール）

このファイルは、川口典礼サイト（kawaguchitenrei.com）の文章・見出し・CTA・
画像 alt・FAQ・施工事例・口コミに共通する文言・トーン・表現ルールを定める。

葬儀社サイトという性質上、**ご遺族・ご家族の心情への配慮を最優先** とする。

---

## 1. トーン（基本方針）

| 軸 | 方針 |
|---|---|
| 落ち着き | 派手な表現・装飾を避け、静かな読み物として読める |
| 誠実さ | 嘘・誇張を避ける。実績は事実のみ |
| 地域密着 | 川口市・新井宿・鳩ヶ谷など、地名を自然に織り込む |
| 押し売りしない | CTA は誘導しすぎず、相談ハードルを下げる |
| 不安を煽らない | 「今すぐ決めないと」「後悔する」などは禁止 |
| 専門用語の補足 | 「直葬」「市民葬」など、初見でわかるように 1 行補足 |

---

## 2. 避ける表現（禁止リスト）

このリストは **サイト本文（訪問者向けに公開する文章）** で避ける表現の一覧。
本ドキュメント群（`CLAUDE.md` / `docs/**`）の内部ルール文で業務指示として
「必ず」「絶対に〜してはいけない」などを使うことはある — それは対象外。

| カテゴリ | 例 | 理由 |
|---|---|---|
| 断定 | 「絶対」「必ず」「100%」「確実に」 | YMYL では断定は危険 |
| 最上級 | 「最安」「最安保証」「最高」「業界 No.1」 | 根拠不在・優劣訴求は競合誹謗にも繋がる |
| 煽り | 「今すぐ決めないと損」「後悔しない唯一の方法」 | ご遺族の心理に付け込む表現 |
| 値段の保証 | 「追加費用は一切ありません」「絶対に追加料金なし」 | 実態と乖離するリスク |
| 過度な感情誘導 | 「涙が止まらない」「人生最後の別れを完璧に」 | 葬儀社サイトとして品格を欠く |
| 他社攻撃 | 「○○社では○○できません」 | 誹謗中傷 |
| 個人特定 | 故人名・喪主名・番地 | プライバシー違反 |

## 4. 価格表記ルール

- **正本**：`CLAUDE.md` §9 のプラン価格テーブル
- **「目安」**と必ず明記
- **税込・税別の区分が確認できない金額には、勝手に「税込」と書かない**
- 「正式なお見積り時に確認」を併記
- 「最安」「絶対追加なし」など断定的価格保証は禁止
- 会員価格と通常価格の **両方** を併記（プラン正本にあるもの）
- 総額モデルでは「プラン本体 + 火葬料 + 式場料 + 宗教者 + 搬送等」のレンジを示す

例（推奨）：
> 一日葬プランは、事前相談会員価格 396,000 円（税込）から。
> 通常価格は 496,000 円（税込）です。
> 別途、火葬料・式場使用料・宗教者へのお礼などが必要になる場合があります。
> 正式なお見積りでご案内します。

## 5. ペット面会の表現ルール

ペット同伴の面会は、川口メモリアルホールの個室面会室の特徴の一つとして扱う。

### 5.1 OK な表現

- 「ペットも大切なご家族の一員と考え、ペットを連れてのご面会にも可能な範囲で対応しています」
- 「ご希望の場合は、事前にご相談ください」
- 「個室面会室では、ご家族・ペットと一緒に静かなお別れの時間を過ごしていただけます」

### 5.2 NG な表現

- 「ペット同伴が必ず可能」（断定）
- 「ペット葬儀・ペット火葬もお任せください」（**面会セクションでは禁止**）
- ペット葬儀ページ（`/pet/`）への導線（**面会セクションでは禁止**）

### 5.3 なぜ面会セクションでペット葬儀導線を入れないか

- 故人様との面会・お別れの文脈にペット葬儀を混ぜると、縁起・配慮の観点でふさわしくない
- 「ペットも家族」の尊重と、ペット葬儀への送客は別文脈で扱う
- ペット葬儀・ペット火葬の訴求は `/pet/` 内で完結させる

## 6. 競合比較の表現ルール

詳細は `docs/02-competitor-analysis-summary.md`。要点：

- 他社固有名詞を出す場合は **事実・公開情報のみ**
- 優劣の **断定はしない**（「○○より安い」「○○より良い」は NG）
- **カテゴリ比較は可**（「大手ポータル型」「互助会型」「地元葬儀社型」など）
- 比較表は **両論併記**（長所と短所を両方書く）
- 「川口典礼の場合」は最後に置き、控えめに

## 7. FAQ 作成ルール

### 7.1 質問の書き方

- 検索クエリに近い文体（「○○はできますか？」「○○の費用はいくらですか？」）
- 1 文で完結
- 主語を省略しない（「葬儀は…」のように）

### 7.2 回答の書き方

- **結論先出し**：1 文目で「はい / いいえ / 場合による」を明示
- 結論の **理由・補足** を 1〜2 文
- **確認導線**：「正式なお見積り時に確認」「お電話でもご相談いただけます」など
- 1 回答 100〜250 字程度を目安

### 7.3 構造化データ

- `FAQPage` を出力
- 質問・回答ともに HTML エンティティを正しくエスケープ

## 8. 施工事例作成ルール

詳細は `docs/04-privacy-review.md` §7。要点：

- **故人名・喪主名を出さない**
- 地域は町名まで（番地・建物名は禁止）
- 宗派は粒度を抑える
- 年齢は年代表現
- 「人数 / 日数 / 形式 / 斎場 / 概算費用」の表を含める
- 「ご家族の声」は要約。一字一句の創作はしない

## 9. 口コミ掲載ルール

詳細は `docs/04-privacy-review.md` §7。要点：

- **イニシャル + 年代 + 地域**（町名まで）
- 一字一句の創作禁止
- 「ご家族の声」を要約として掲載
- 構造化データは `Review` を使い、`itemReviewed` は法人またはホール

## 10. 見出し（h1 / h2 / h3）の書き方

| レベル | 文末 | 文字数目安 |
|---|---|---|
| h1 | 「。」を付けても付けなくてもよい。短く | 全角 10〜25 字 |
| h2 | 「。」で締めるトーンに統一 | 全角 10〜30 字 |
| h3 | 「。」で締めるか、体言止め | 全角 8〜20 字 |

例：
- h1：「川口市・新井宿の家族葬。」
- h2：「川口メモリアルホールの特徴。」
- h3：「個室面会室について。」

## 11. CTA 文言

| 文脈 | 推奨文言 |
|---|---|
| メインCTA（電話） | 「電話で相談する」「電話で確認する」 |
| メインCTA（フォーム） | 「事前相談する」「葬儀場について相談する」「費用の見積りを依頼する」 |
| 副 CTA（資料） | 「詳しく見る」「○○の詳細を見る」 |
| 補足 | 「24 時間 365 日 受付」 |

NG：
- 「今すぐ電話！」「最短即日対応！」（煽り）
- 「お問い合わせはこちら」（汎用すぎる）

---

## 12. 画像 alt の書き方

- **内容を具体的に**（「川口メモリアルホールの外観」「個室面会室でペットと一緒にお別れする様子」）
- 装飾画像は `alt=""` または `aria-hidden`
- 個人特定情報を入れない（人名・施設名以外の詳細）
- 100 字以内を目安

---

## 13. 内部リンクテキスト

- 「こちら」「詳しくはこちら」は使わない
- リンク文言にキーワードを含める
  - NG：「詳しくはこちら」
  - OK：「家族葬プランの詳細を見る」「川口市めぐりの森の葬儀案内を見る」

---

## 14. 表記揺れ

| 統一表記 | 揺れの例 |
|---|---|
| 川口典礼 | 川口典禮（旧字を避ける） |
| 川口メモリアルホール | メモリアルホール（単体使用は避ける） |
| 川口市めぐりの森 | めぐりの森（単体使用は文脈次第で可） |
| 家族葬 | 家族葬式（誤用） |
| 一日葬 | 1 日葬（漢数字に統一） |
| 直葬 | チョクソウ（カタカナ化禁止） |
| 火葬式 | 直葬と同義扱いだが、ページごとに統一 |
| 24 時間 365 日 | 全角 / 半角どちらかに統一（既存に合わせる） |

---

## 15. 句読点・記号

- 「、」「。」を基本（カンマ・ピリオドは使わない）
- 「！」「？」は控えめに（FAQ の質問末以外では避ける）
- 「〜」（波線）は使う（「10〜30 名」など）
- 数字は半角を基本（「20 年」「70 台」）
